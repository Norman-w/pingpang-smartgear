# ESP32 主控系统：机械—电气接口合同 v0.2

状态：**机械统一坐标、板件包络、壳内安装、过线和盒盖贴合检查已完成；KiCad/Atopile 文件已在仓库，电气生产释放仍 OPEN。**

本文件是 `hardware/cad/net_stand.scad`、ESP32 母板和三个子板的共同约束。当前版本已经把真实 KiCad 板框/器件 3D 包络放进壳体同一坐标系，并由 [`validate_system_fit.py`](validate_system_fit.py) 做 AABB、布尔干涉、OpenSCAD 视图和打印清单自检；正式走线、器件实测和实物首样仍是下一道电气放行门。

### 母板的尺寸结论

当前梯形腔有效范围为 `102.8 × 40 mm`。母板 `86 × 32 mm` 放入后：

- x 向总余量 `16.8 mm`，理论两端各 `8.4 mm`；
- y 向板框总余量 `8 mm`，实际按器件包络与插拔方向校核；
- PCB 上表面到腔顶预留 `5 mm`，按最高顶面器件 `4 mm` 加 `1 mm` 装配余量；
- 四个安装孔中心距母板边 `4.5 mm`，孔为 `Ø2.8 mm NPTH`，不会侵入 ESP32 天线禁布区；
- 母板不把侧插连接器硬塞进 3 mm 边隙，外部线束改由盖板/端壁上的端子或防松出线件接入。

因此母板尺寸足够，且不会干涉梯形腔；所有需要较多现场接线的部分拆到子板，避免“板虽能放下、插头却插不进去”。板框尺寸按空腔允许范围尽量收紧，但保留器件间距、走线通道和插拔操作空间。

### 光学间距与 PCB 尺寸解耦

发射头/接收头的距离和 `20 mm` 光学排列只决定两侧光学头集模组及其线束长度，不决定接收载板的长度。十路接收头的 `BN/BU/BK` 三芯线先在机械侧汇成线束，再分别插入紧凑接收板的 `J_RX00…J_RX09`；因此接收板改为 `80 × 32 mm` 的两排五路接口/采集区，板内排列不表示光学头的物理间距。十路发射头的 `BN/BU` 两芯线同样在进入发射电源板前汇线，板上用 `J_TX_A/J_TX_B` 两个 10 芯段承接。

统一坐标检查的关键实测于 CAD 包络为：母板实际模型到腔体侧壁最小余量 `0.395 mm`、最高器件到腔顶余量 `1.005 mm`；发射板最小余量 `3.000 mm`，UI 板 `6.000 mm`，电池包 `2.000 mm`。M6 载板竖直放入接收壳后最小边界余量 `1.500 mm`，实际器件包络与光学壳体之间保守余量 `2.910 mm`。这些是模型包络值，不替代打印收缩和真实连接器试装。

## 2. 接线方式

现场可拔插线全部采用以下方式之一：

1. 带防呆的锁扣式线对板连接器，物理节距统一为 `MX1.25`（1.25 mm）；
2. 外部 10–30 V 电源使用可插拔螺钉端子或压接端子；
3. 电池使用带极性防呆和锁扣的 2 芯端子；
4. M6 传感器按 `RX00…RX09` / `TX00…TX09` 编号做成线束，端头压接后插入对应 MX1.25 锁扣座；发射端在板上分为 `J_TX_A`/`J_TX_B` 两个 10 芯接口。

不采用裸焊盘接外部线、不采用没有应力释放的飞线。每根线束两端都贴 `SIDE / CH / SIGNAL` 标签，并在子板上留测试点。

## 3. ESP32-S3 信号预算

主控采用 ESP32-S3-WROOM-1-N16R8 首样模块。低 GPIO 区域按下面合同使用，已经覆盖当前功能，不再额外占用启动、USB、PSRAM 或调试专用脚：

| 功能组 | 信号 | GPIO |
| --- | --- | --- |
| PVDF | `pvdf_adc_l/r` | GPIO1 / GPIO2 |
| 交互按钮 | `ui_btn_start/mode` | GPIO3 / GPIO4 |
| 载板复位 | `carrier_reset_n` | GPIO5 |
| 扬声器 I2S | `ui_spk_bclk/ws/dout` | GPIO6 / GPIO7 / GPIO17 |
| 蜂鸣器 | `ui_buzzer` | GPIO8 |
| 电池采样 | `bat_sense` | GPIO9 |
| M6 载板 SPI/IRQ | `sck/mosi/miso/cs/irq` | GPIO10…GPIO14 |
| UI I2C 屏 | `ui_scl/sda` | GPIO15 / GPIO16 |
| 指示灯 | `ui_led_status/battery` | GPIO18 / GPIO21 |
| 原生 USB | `USB_D-/USB_D+` | GPIO19 / GPIO20 |
| 启动/调试保留 | `BOOT`, UART0 | GPIO0, GPIO43/44 |

这套分配是 21 个低 GPIO 的完整功能预算；如果以后要增加屏幕复位、旋钮或更多按键，应在 UI 子板上加 I2C GPIO 扩展器，不得临时抢占 M6 SPI、USB 或启动脚。

## 4. 电源域

```text
主控腔：受保护 1S 电池 -> IP5305T 5 V -> TPS62162 3.3 V -> ESP32/UI/逻辑
接收端：外部 10–30 V -> 保险/TVS -> SENSOR_RAIL -> 接收载板/接收头
发射端：内置受保护 1S 电池 -> 独立升压/限流模块 -> TX_RAIL -> 十路发射头
```

- 发射器默认内置电源，电池和升压模块放在左侧零件较少的腔体；
- 发射电源子板同时保留 `EXT_TX_IN` 可插拔 10–30 V 输入，内置电源暂时不用时仍可外接；
- 发射端电源不能从 ESP32 的 3.3 V/5 V 逻辑电源直接取；
- 外部电源入口、保险丝/PTC、TVS、反接和线束应力释放都在子板/端子侧完成；
- 电池只允许带保护板的成品 1S 电池包，电量采样只用于估算，不替代保护电路。

## 5. 交互件与盖板

- 两个面板按钮：3.9×3.0×2.0 mm 两脚 SMD PCB 直装按键，封口板用浅凹面和腔内 1.6 mm 导向柱接触，分别对应 `START`、`MODE`；
- 屏幕：预留 0.96 英寸 I2C OLED 区域，屏幕与封口板之间用透明窗/内侧支承，不让屏幕裸露在腔体缝隙；
- 指示灯：两个 0603 单色 LED 直接焊在 UI PCB 上，使用 KiCad 封装 3D 模型随板 STL 导出，各自对准封口板 2.2 mm 直孔；不在 SCAD 中重复创建 LED 芯片或 LED 包络，也不引入额外 RGB/WS2812 走线；
- 蜂鸣器：使用带声学膜/防护网的器件，不能在盖板上留下裸通孔；
- 扬声器：使用带防尘防溅声学膜的单元，封口板只开受控的声学窗口并配压框；
- USB-C：16 针 USB-C 插座直接焊在 UI PCB 上，使用 KiCad 库模型随板 STL 导出，并在 UI 垂直安装坐标中旋转到 y+ 面板法向，端口穿过封口板并配硅胶帽；具体厂家尺寸/料号在首样前冻结；屏幕仍保留排线连接，屏幕/扬声器等线束件由 SCAD 装配层定义。

## 6. UI 面板与过线要求

电子腔不再使用独立底盖、连续垫或旧的 UI 压框。y+ 侧窗由一体式 UI 填平固定板从腔内 y- 侧推入，外表面与 C 夹壁齐平；腔内法兰、捕获环和 8 个通孔与面板同一 STL，使用 8 枚 2 mm 蘑菇头自攻钉直接进入 C 夹内壁盲导孔。这里的“齐平”只指装配后不能出现明显错台或松动，不宣称 IP 等级。

- UI 面板保留连续承托边和腔内装配导向；固定力由 8 个腔内螺钉均匀传回 C 夹实心内壁，不靠外侧装饰孔或旧 boss；
- 面板周边保持打印配合余量，不能让单个螺钉把面板拉成翘曲；
- M6 前盖、后盖、底盖均有连续搭接/压合面；底部出线改为多孔压紧件或灌封压线套，并配滴水弯/应力释放；
- 过线参考固定为“每侧独立汇线”：右侧 `RX00…RX09` 三芯线进入接收子板，左侧 `TX00…TX09` 两芯线进入发射电源子板；左右不共用一根无标签线束；
- 盖板装好后只用塞尺/纸条和开合手感检查周边贴合，目标是无可见贯通缝、无明显错台、无松动；不安排浸水、压力气密或 IP 等级测试。
