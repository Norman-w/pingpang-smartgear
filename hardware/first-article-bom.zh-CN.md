# 乒乓智配首样采购与装配清单 v0.3

本文服务于第一套“替换传统球网”的实体样机。打印件数量以 [`cad/print-manifest.zh-CN.md`](cad/print-manifest.zh-CN.md) 和导出 `manifest.json` 为准；这里区分打印件、标准紧固件、外购器件和仍需实测的项目。

## 1. 打印件

由 [`cad/net_stand.scad`](cad/net_stand.scad) 导出当前 `37` 件正式包：`31` 件 PETG、`6` 件 TPU/柔性。当前 256 mm 拼盘结果为 `6` 张板、`37` 件已排版、`0` 件超尺寸；两件整根立柱从 `z=16` 一体延伸到 `z=372.5 mm`，首样锁定 `rx=0°、ry=51°、rz=45°` 三轴斜放，实际变换包络约 `252.5×252.5×251.6 mm`，按该件专用 `1.5 mm` 名义边缘余量排版。正式矩阵包括：

| 打印件 | 数量 | 作用 |
| --- | ---: | --- |
| `post_clamp_carrier` | 2 | 整根立柱 + 连续 `3 mm` 网布过道；底面与 C 夹黄灰交界 `z=16 mm` 共面，实体连续到 `z=372.5 mm`（总高 `356.5 mm`）；网布/卡夹功能区仍到 `z=168.5 mm`；从承托面起 `30 mm` 连续实心渐变，由 `35×58 mm` 收至 `28×38 mm` 后保持恒定；不向下插入 C 形座，不携带额外滑轨、滑靴或独立固定壁 |
| `clamp_body_segment` | 2 | 完整桌下 C 形固定主体、梯形电子腔、完整外侧 C 壁和立柱下端固定承托面；除网/卡网功能开口外保持实心 |
| `clamp_electronics_cover/gasket/ui_bezel` | 各 2 | 梯形腔盖、连续压合件和按钮/屏幕/指示灯/声学/USB-C 面板压框 |
| `m6_detector_body`、前盖、后盖、底盖、底盖 gasket、cable gland | 各 2 | 左右十路 M6 发射/接收壳体；主体包络 `10 × 56 × 216 mm` |
| `net_clamp_clip` | 2 | 整高 U 形卡网夹；平放打印，安装时沿 x 从桌外侧滑入 |
| `clamp_pressure_pad`、`clamp_printed_screw`、`clamp_body_nut`、`clamp_knob`、`clamp_knob_nut` | 各 2 | 台底压块、12 mm/4 mm PETG 粗牙螺杆（2 mm 牙顶/2 mm 凹槽）、固定螺母、旋钮和每侧两枚对锁螺母 |
| `sensor_mount_body`、`sensor_clamp_lip` | 各 2 | 网端 PVDF 座和可拆压片 |
| `calibration_gauge` | 1 | 过网高度标定规 |

正式清单不包含网顶轨道、轨道拼接片、传统圆柱卡网件、旧立柱套筒/内芯或历史外挂光学载台。旧名字只可用于回溯诊断，不能混入本次打印包。

## 2. 机械标准件和网布

| 物料 | 数量 | 当前接口和作用 | 状态 |
| --- | ---: | --- | --- |
| M4 连接螺钉 + 螺母 | 4 套 | 绿色整体底座推入灰色让位腔后的接口锁紧；钢珠只定位，不承主载荷 | 首样采购 |
| M5 分型面螺钉 + 六角螺母 | 18 套 | 每只 C 夹 9 处横向连接；只在电子仓空腔边界使用 boss | 首样采购 |
| M4×30 螺钉 + 螺母 | 0 | 当前整根立柱与固定 C 夹不使用旧版滑轨防滑脱件；若首样另需定位件，必须单独复核，不计入当前正式结构 | 不进入当前打印/装配主线 |
| 4 mm 钢球 + 3 mm 短压簧 + 保持头 | 0 | 当前版本不使用旧版滑轨咯噔定位件 | 不进入当前打印/装配主线 |
| 真实乒乓球网/网布及白边 | 1 套 | 先从球台中心侧穿过立柱 `3 mm` 过道，端部止到立柱外表面，再装 U 夹 | 待实物确认 |
| 台面上侧 TPU/硅胶保护片 | 2 | 粘贴在固定上夹板与桌面之间，防滑和保护台面 | 现场裁切 |
| 台底薄软垫 | 2 | 可贴在台底压块接触面；压块主体仍是刚性 PETG 试样 | 按目标台面确认 |

立柱与 C 夹的承力原则：

- 固定灰色完整 C 形主体除网/卡网功能开口外保持实心；整根 `post_clamp_carrier` 的底面直接落座到 C 夹黄灰交界 `z=16 mm`，立柱实体连续到 `z=372.5 mm`；网布/卡夹功能区止于 `z=168.5 mm`，不向下插入 C 形座。
- 从 `z=16 mm` 承托面向上 `30 mm`（至 `z=46 mm`）做封闭实心连续渐变，底端 `35×58 mm` 收至 `28×38 mm` 顶端截面；立柱本体没有上下接缝、脚、裤裆、滑靴或外套圈，也不切固定网柱顶端 M8 直连孔。
- 结构载荷由连续立柱实体、C 夹固定基台和桌下夹紧路径承担；网端卡夹由网布张力和绳的拉力压在承托面上，立柱内嵌单一被动止挡只防止卡夹向外拔出，不使用穿钉或螺钉承受网布主拉力。

## 4. 首样装配顺序

1. 按 manifest 打印并检查左右夹体、立柱、电子腔盖/压合件、M6 壳体、卡网夹、PVDF 件和夹紧件；先不装网布和通电器件，使用目标台厚样块确认 C 形夹开口、压块和粗牙螺杆行程。
2. 将完整固定 `clamp_body_segment` 固定在目标球台边缘，再装入整根 `post_clamp_carrier`；确认立柱底面与 C 夹承托面 `z=16 mm` 共面，实体连续到 `z=372.5 mm`，网布/卡夹功能区止于 `z=168.5 mm`，接触面以上 `30 mm`（至 `z=46 mm`）为连续实心渐变，之后保持 `28×38 mm`，且没有下插段、旧版滑轨、滑靴或额外防滑脱件。
3. 不再安装立柱分件、接缝套筒或固定网柱顶端 M8 直连件；确认整根立柱的网布通道、球头独立支撑预留、线缆方向和网布高度。
4. 把网布端部从球台中心侧穿过立柱 `3 mm` 过道，使网布端停在立柱外表面；再把平放打印的 U 夹立起，从桌外侧沿 x 推入，确认两片 jaw 夹住网布，内嵌止挡咯噔落入释放位；不装穿钉，拆卸时按开夹爪后反向滑出。
5. 安装两侧十路 M6 器件、接收载板、发射电源子板和两只受保护电池；按 `RX/TX` 标签接入端子，检查线缆弯曲、应力释放和左右发射/接收方向。
6. 安装 PVDF 薄膜/压片、主控板、UI 子板和电子腔盖；检查按钮、屏幕窗口、指示灯、声学窗口、USB-C 帽和连续压合边，确认无明显贯穿缝、错台或翘边。
7. 按电子 bring-up 文档完成断电检查、限流上电、M6 输出、PVDF 基线、SPI/IRQ 和电池采样记录。任何健康门失败时，系统状态保持 `unknown`。

## 5. 尚不能由 CAD/BOM 证明的项目

- PETG 夹体在真实夹紧力、网布张力和反复拆装下的滑移/变形/耐久；
- 立柱与固定 C 夹的实际打印配合间隙、落座稳定性、内嵌止挡的防拔可靠性和 U 形卡夹耐久；
- 盒盖压合件的打印收缩、胶条压缩量、实际线缆弯曲半径和盖面开口贴合；
- 电池容量、升压峰值电流、温升、M6 供电/输出语义、光耦波形和最终铜箔 DRC/ERC；
- 真实球台厚度、网布白边厚度、网高、左右平行度以及光轴对准。

这些项目须记录照片、量具、示波器/逻辑分析仪或实物装配结果后再改为 `PASS`。当前“水密”只代表盒盖装好后严丝合缝，不代表 IP 防水等级。
