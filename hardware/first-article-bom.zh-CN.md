# 乒乓智配首样采购与装配清单 v0.4

本文服务于第一套“替换传统球网”的实体样机。打印件数量以 [`cad/print-manifest.zh-CN.md`](cad/print-manifest.zh-CN.md) 和导出 `manifest.json` 为准；这里区分打印件、标准紧固件、外购器件和仍需实测的项目。

## 1. 打印件

由 [`cad/net_stand.scad`](cad/net_stand.scad) 导出当前 `41` 件正式包：`37` 件 PETG、`4` 件 TPU/柔性。当前 256 mm 拼盘结果为 `7` 张板、`41` 件已排版、`0` 件超尺寸；斜立柱下段/绿色载体采用 `rx=0°、ry=51°、rz=45°` 三轴斜放，上段按分型面平放，按当前 X1C 排版清单复核支撑和首层。正式矩阵包括：

| 打印件 | 数量 | 作用 |
| --- | ---: | --- |
| `post_clamp_carrier_lower`、`post_clamp_carrier_upper` | 各 2 | 斜立柱下段/顶部下 `30 mm` 上段；下段含绿色底座、连续 `3 mm` 网布过道和 x 侧开圆柱接收腔，上段含公母键、四枚 `Ø3.4 mm` 通孔和顶部 M8 支撑孔；两段在 `z=230.5 mm` 分型并用普通盘头/低矮圆头 M3×40 自攻钉连接 |
| `clamp_body_half_user`、`clamp_body_half_opponent` | 各 2 | y=0 分型的操作者侧/对手侧 C 形夹半体；合拢形成完整桌下 C 形固定主体和梯形电子腔，主板由两端 `[`/`]` 夹件承托，不再使用旧整件夹体 |
| `clamp_electronics_ui_panel_mount` | 2 | y+ 外侧齐平 UI 填平固定板；面板、腔内 72×42 mm 搭接法兰、捕获环和 8 个通孔融合为一件，从腔内装入并用 2 mm 蘑菇头自攻钉固定 |
| `m6_detector_body`、前盖、后盖、底盖、底盖 gasket、cable gland | 各 2 | 左右十路 M6 发射/接收壳体；主体包络 `10 × 56 × 216 mm` |
| `net_clamp_rod` | 2 | 独立 `Ø10 mm × 152.5 mm` 圆柱插杆；平放打印，先穿过球网空心边套，再沿原门洞轴线从 x 侧推入下段侧开接收腔 |
| `clamp_pressure_pad`、`clamp_printed_screw`、`clamp_body_nut`、`clamp_knob`、`clamp_knob_nut` | 各 2 | 台底压块、12 mm/4 mm PETG 锥形粗牙螺杆（2 mm 牙根/2 mm 凹槽/0.4 mm 锥尖）、固定螺母、旋钮和每侧两枚对锁螺母 |
| `sensor_mount_body`、`sensor_clamp_lip` | 各 2 | 网端 PVDF 座和可拆压片 |
| `calibration_gauge` | 1 | 过网高度标定规 |

正式清单不包含网顶轨道、轨道拼接片、传统圆柱卡网件、旧立柱套筒/内芯或历史外挂光学载台。旧名字只可用于回溯诊断，不能混入本次打印包。

## 2. 机械标准件和网布

| 物料 | 数量 | 当前接口和作用 | 状态 |
| --- | ---: | --- | --- |
| M4 连接螺钉 + 螺母 | 4 套 | 绿色整体底座推入灰色让位腔后的接口锁紧；钢珠只定位，不承主载荷 | 首样采购 |
| M5 分型面螺钉 + 六角螺母 | 18 套 | 每只 C 夹 9 处横向连接；只在电子仓空腔边界使用 boss | 首样采购 |
| M4×30 螺钉 + 螺母 | 0 | 当前斜立柱上下段与固定 C 夹不使用旧版滑轨防滑脱件；若首样另需定位件，必须单独复核，不计入当前正式结构 | 不进入当前打印/装配主线 |
| 4 mm 钢球 + 3 mm 短压簧 + 保持头 | 0 | 当前版本不使用旧版滑轨咯噔定位件 | 不进入当前打印/装配主线 |
| 真实乒乓球网/网布及白边 | 1 套 | 先把空心边套套到 Ø10 圆柱插杆，再从球台中心侧穿过立柱 `3 mm` 网布过道并沿 x 推入侧开接收腔 | 待实物确认 |
| 台面上侧 TPU/硅胶保护片 | 2 | 粘贴在固定上夹板与桌面之间，防滑和保护台面 | 现场裁切 |
| 台底薄软垫 | 2 | 可贴在台底压块接触面；压块主体仍是刚性 PETG 试样 | 按目标台面确认 |

立柱与 C 夹的承力原则：

- 固定灰色完整 C 形主体除网布/边套过道外保持实心；`post_clamp_carrier_lower` 的底面直接落座到 C 夹黄灰交界 `z=16 mm`，上段在 `z=230.5 mm` 与下段分型并延伸到 `z=260.5 mm`；网布/圆柱插杆功能区止于 `z=168.5 mm`，不向下插入 C 形座。
- 从 `z=16 mm` 承托面向上 `30 mm`（至 `z=46 mm`）做封闭实心连续渐变，底端 `35×58 mm` 收至 `28×38 mm` 顶端截面；立柱本体没有上下接缝、脚、裤裆、滑靴或外套圈，也不切固定网柱顶端 M8 直连孔。
- 结构载荷由连续立柱实体、C 夹固定基台和桌下夹紧路径承担；网端由套在 Ø10 圆柱插杆上的空心边套定位，圆柱插杆沿 x 推入下段侧开接收腔并由上段封住入口；网布张力、插杆和立柱实体的实际承载仍需首样确认。

## 4. 首样装配顺序

1. 按 manifest 打印并检查左右两片 C 夹半体、斜立柱下段/上段、UI 一体式填平固定板、M6 壳体、圆柱插杆、PVDF 件和夹紧件；先不装网布和通电器件，使用目标台厚样块确认 C 形夹开口、压块和粗牙螺杆行程。
2. 将左右 `clamp_body_half_user` 与 `clamp_body_half_opponent` 在 y=0 分型面合拢并固定到目标球台边缘，再装入 `post_clamp_carrier_lower`，把 `post_clamp_carrier_upper` 滑入 `z=230.5 mm` 分型面并用四枚普通盘头/低矮圆头 M3×40 自攻钉连接；确认立柱底面与 C 夹承托面 `z=16 mm` 共面，实体到 `z=260.5 mm`，网布/圆柱功能区止于 `z=168.5 mm`，且没有下插段、旧版滑轨、滑靴或额外防滑脱件。
3. 确认上下立柱分件的公母键、四枚 M3×40 螺钉和顶部 M8 支撑孔；网布通道在下段，球头独立支撑由上段承载。
4. 把球网侧边空心布套套到 `Ø10 mm × 152.5 mm` 圆柱插杆上，从球台中心侧把这套组件穿过立柱的 `3 mm` 网布过道，再沿原门洞轴线从 x 侧推入下段侧开接收腔；确认插杆落座并保持入口可由上段封住，随后安装上段捕获圆柱。实际布套内径、插杆材料和推入力需首样实测。
5. 安装两侧十路 M6 器件、接收载板、发射电源子板和两只受保护电池；按 `RX/TX` 标签接入端子，检查线缆弯曲、应力释放和左右发射/接收方向。
6. 安装 PVDF 薄膜/压片、主控板和 UI 子板；将左右一体式 `clamp_electronics_ui_panel_mount` 从腔内 y- 侧推入 y+ 侧窗，再从腔内拧入 8 枚 2 mm 蘑菇头自攻钉。检查按钮、屏幕窗口、指示灯、声学窗口和 USB-C 碗槽，确认无明显贯穿缝、错台或翘边。
7. 按电子 bring-up 文档完成断电检查、限流上电、M6 输出、PVDF 基线、SPI/IRQ 和电池采样记录。任何健康门失败时，系统状态保持 `unknown`。

## 5. 尚不能由 CAD/BOM 证明的项目

- PETG 夹体在真实夹紧力、网布张力和反复拆装下的滑移/变形/耐久；
- 立柱与固定 C 夹的实际打印配合间隙、落座稳定性、侧开接收腔的防脱可靠性和圆柱插杆耐久；
- 盒盖压合件的打印收缩、胶条压缩量、实际线缆弯曲半径和盖面开口贴合；
- 电池容量、升压峰值电流、温升、M6 供电/输出语义、光耦波形和最终铜箔 DRC/ERC；
- 真实球台厚度、网布白边厚度、网高、左右平行度以及光轴对准。

这些项目须记录照片、量具、示波器/逻辑分析仪或实物装配结果后再改为 `PASS`。当前“水密”只代表盒盖装好后严丝合缝，不代表 IP 防水等级。
