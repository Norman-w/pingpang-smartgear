# 硬件工程

这里放置内置式球网支架、替换球网、连续光栅导轨、带有限俯仰/偏航调节槽的光学载台、参考线、PVDF 网顶夹片、红外收发器和装配资料。

## 当前硬件拆分

- `cad/`：当前内置式球网支架的参数化 OpenSCAD、左右镜像件和装配预览；
- `electronics/`：PVDF AFE、调制红外光栅和板级接口边界；

当前打印件由 `cad/net_stand.scad` 这一份参数源统一导出：它包含左右两段式立柱、下段与传统桌下 C 形夹一体的 `lower_stand_segment`、接缝外套筒/内芯、固定上夹板与桌面之间的可替换保护垫、台底可动压块、网顶承载条、光学模块安装位和 PVDF 夹片安装位。打印数量、标准件和非打印装配边界见 [`cad/print-manifest.zh-CN.md`](cad/print-manifest.zh-CN.md)。

首版按 `1525 mm` 球台宽度、`25 mm` 台面厚度、`37 mm` 立柱外置距离和 `152.5 mm` 网顶高度起模；当前支架免打孔，固定 C 形夹体跨过台边，上夹板与桌面之间放置可替换 TPU/硅胶保护垫，固定下臂捕获一枚 M8 螺母，旋钮捕获另一枚 M8 螺母，圆头 M8×1.25 螺杆在台面下方顶起独立可动压块夹紧台底，不依赖 PETG 内螺纹；光学导轨位于台边与立柱内缘之间的开放空间，光轴覆盖球台边缘。最终兼容范围必须以实物测量、夹持力、滑移和网布张力记录为依据。当前不包含相机作为本体测量链路；外部视频设备只用于后续时间戳回放复核。原 `cad/net_post_x_clamp.scad` 是保留的外挂 X 夹具历史方案，不是当前主线。
