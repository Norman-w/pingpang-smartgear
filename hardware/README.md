# 硬件工程

这里放置内置式球网支架、替换球网、连续光栅导轨、参考线、PVDF 网顶夹片、红外收发器和装配资料。

## 当前硬件拆分

- `cad/`：当前内置式球网支架的参数化 OpenSCAD、左右镜像件和装配预览；
- `electronics/`：PVDF AFE、调制红外光栅和板级接口边界；

当前打印件由 `cad/net_stand.scad` 这一份参数源统一导出：它包含左右立柱、传统桌下上下夹持面、网顶承载条、光学模块安装位和 PVDF 夹片安装位。打印数量、标准件和非打印装配边界见 [`cad/print-manifest.zh-CN.md`](cad/print-manifest.zh-CN.md)。

首版按 `1525 mm` 球台宽度、`25 mm` 台面厚度和 `152.5 mm` 网顶高度起模；当前支架免打孔，夹紧螺杆位于台边外侧，仅从上下接触面夹住台面边缘。最终兼容范围必须以实物测量、夹持力、滑移和网布张力记录为依据。当前不包含相机作为本体测量链路；外部视频设备只用于后续时间戳回放复核。原 `cad/net_post_x_clamp.scad` 是保留的外挂 X 夹具历史方案，不是当前主线。
