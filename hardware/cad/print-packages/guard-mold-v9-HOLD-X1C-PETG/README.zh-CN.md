# v9 螺杆全部竖直、大头朝下（仅3MF，暂不打印）

X1C、0.4mm喷嘴、黑色PETG。保留v7功能模型、打印粗牙和模具一体母牙，不使用独立螺母或热熔嵌件。本版不生成ZIP、不发送打印。

## 数量与五板

1. 全部紧固杆：X×1、Y×2、Z×4；拆模J×2，共9根，统一绕源X轴180°，旋钮/大头平面贴床、螺纹朝上。长杆没有任何横放实例。
2. A/B外模：沿用v8已切片和审计的底座朝下、横向分排姿态。
3. E芯块，原横放Z4已移至第1板。
4. F/D/G，原横放X和J已移至第1板。
5. C盖板：沿用v8已验证的正放姿态与定位柱短脚。

使用件合计16件，安装紧固杆7根全部配齐，拆模J杆只2颗轮换用。板2和板5从已验证v8原样继承；改变的板1/3/4重新真实切片。

## 防倾倒与支撑

9根杆各有外径56mm、1.2mm高的可剪除环形底圈，六条2.4mm宽、0.4mm高的外侧薄连接片接至旋钮外缘，不穿过中心字母。安装杆底圈内径41mm，J底圈内径45mm。

旋钮大平面保持直接贴床，圈外扩增加首层接触面积；不是让杆尖着床，也没有把杆横架在支撑上。底圈打印后先剪除、修平残根，再装配。底圈不留在使用中的旋转、螺纹或贯穿孔路径内。

第1板逐对象关闭自动支撑，并检查实际G-code支撑走线为0；仅凭切片元数据support_used标志不能代替走线核对。其余模具必要支撑继续保留，清除后才能合模。模型静态重心及接触面积检查不是实物抗倾倒或粘附力验收。

安装杆和J保持6墙、100%填充，0.2mm层高。竖打后的轴向层间承载、牙面质量和实际配合仍待试件验证，不宣称已通过实物强度测试。

## 装配通路

原SCAD及功能STL来自../guard-casting-mold-v7。所有防倾倒辅助件移除后，恢复同一功能模型：螺杆后装，从旋钮一侧的光孔贯穿至远端一体母牙，退下整根后拆模；不是永久封闭捕获式，也不需要先装螺杆再打印。

v7的螺旋路径、错误相位对照、装配零交叠验证继续适用；v9逐件核对来源SHA256和不缩放，辅助几何只增加、不切除功能体。母牙、连续孔和头根让位不变。C的定位柱短脚用剪钳剪除，不把短脚当成永久延长定位柱。
