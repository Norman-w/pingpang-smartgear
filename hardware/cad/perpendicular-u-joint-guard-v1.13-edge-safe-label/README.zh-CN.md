# v1.13：小号顶面字样与阳边倒角

## 机械约定

一体PETG FDM件，单位mm；X=灰色上方长管，Y=蓝色脚，Z向上。沿用v1.12平整盖底；没有改变安装方向、卡臂、屋檐或斜坡的总体布置，不使用外部紧固件连接打印件。

- 顶盖靠-Y一侧新增沿X排布的`Norman@PingCloud`凸字，Arial Bold、字号3；约40.06×3.91，露出盖顶0.6，埋入0.1，字边另做0.1微倒角。文字与顶盖合并为同一实体；审图用金色只是对比色，不是多色打印设置。
- 主体所有凸出阳边、阳角使用0.6的八面体核开运算退让倒角，包括屋檐的顶底边、立墙竖边/端边、斜坡边、方管通道口沿和圆孔口沿，不是仅切四个顶角。轴向直角边形成45°平面；斜面交线的实际退让量随原夹角变化。
- **唯一豁免区是最底1.5 mm整层，Z=-23.5..-22：由原模型完整保留，内扣厚度、咬合尖端和外角不变。** 该区域没有被安全倒角削薄，其自身边缘也不宣称已去锐。
- 主体处理限定在原实体内，不向方管配合空间添加材料；内腔平面位置、盖底Z=23、盖顶主体Z=31与中部8 mm屋盖保留，倒角只退让边缘。Ø16主孔直段保留，口沿做退让。

方法直接作用于SCAD实体，不导入STL替代几何源。`edge_safe_guard.scad`依赖v1.12→v1.11，历史文件未改。

CGAL布尔检查：主体没有新增占位；最底1.5 mm与v1.12双向差集为空；Ø15.99探针孔内无障碍；盖底原凸条区域无残留。正文细节不进入孔：文字的Y范围约-17.456..-13.544，离孔半径8以外有余量。前视、俯视及等轴图检查边缘和字样。

最终主STL为8872面、4436顶点，封闭流形，退化面/边界边/非流形边/方向错误均0；外包55.8×67×55.1（含顶部0.6凸字），体积55102.494562 mm³。结果另见审图目录`stl-inspection.json`。

使用分阶段导出：同一原生SCAD的主体用CGAL精确布尔，曲线文字用Manifold，最后将两个派生网格合并成单一打印实体。Manifold直接试导整件时，主体开运算处产生亚微米薄片/退化面；CGAL直接计算整件曲线字体时触发内部断言，均不作为交付路径。`assemble_export.scad`只是导出流水线的网格装配器，不代替原生SCAD权威来源。不要把试导`body-test.stl`、`label-test.stl`或残面探针当作打印入口。

```sh
python3 hardware/cad/perpendicular-u-joint-guard-v1.13-edge-safe-label/build_export.py
```

模型、源文件、审图及正式STL本次一并纳入Git归档；没有制作新3MF或发送打印。新文字需要切片确认细笔画及打印朝向；阳边倒角不等于保证不会碰伤，仍需打印后检查毛刺和支撑残留，底扣豁免区尤其如此。原来的地面空间、实物松紧、回弹、止转和强度门槛仍需首件验证。
