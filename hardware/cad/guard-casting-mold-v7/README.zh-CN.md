# v7 一体母牙合模与两颗轮用拆模杆

单位mm，X为上梁方向，Y为下脚方向，Z向上。沿用v6的大浇口、排气孔与加固，PU成品型腔不变。

## 打印数量与标记

六块模具A—F各1件，定位销G 1件。安装紧固杆X 1根、Y 2根、Z 4根，全部装齐保留；**无独立螺母**，远端加厚模具座直接做24mm长一体母牙。拆模J杆仅2颗，同规格换位轮用。合计16件。

A左外模、B右外模、C顶盖、D上梁芯、E绿芯、F后芯、G定位销，外露大面阴刻字母；安装杆头刻X/Y/Z，拆模杆刻J。模型不刻长说明。

## 装拆顺序

安装：D → A/B → F/E肩面到位 → C → G → 装齐7根X/Y/Z杆，均匀轻拧。
拆除：先卸全部X/Y/Z杆 → G → C → E → F → A/B → D。两颗J在C、E、F、A/B的对应孔位交替顶开约3mm，退回后再抽该块；D先下降1mm再沿+X抽出。

## 粗牙与承力

定制打印梯形牙，牙芯19mm、外径22mm、导程8mm、牙根5.6mm、牙顶1.6mm，径向间隙0.3mm、轴向每侧0.25mm。不是标准金属螺纹。

安装杆远端一体母牙长24mm（3圈）；Z下耳厚24mm，X端座加厚至外侧X78，Y端座加厚至Y88。近端为光孔与加粗头根让位，远端是母牙。母牙直接把载荷传入模具，不再找单独螺母。J杆长72mm，母座32mm，仍为单独的拆模用途。

## 验证与边界

build.py重建模具、检查单实体及闭合交叠，采样原拆模路径；check_clamps.py检查全部安装杆与模具、彼此干涉；check_screw_assembly.py检查J的8个备选位置。check_ui.mjs检查三维数量、分步及播放。卸安装杆的显隐只是搬运示意，不是螺旋退出路径仿真。

原卡臂0.6mm倒扣仍需柔性PU让位。PETG层间强度、蠕变、实际预紧力和浇注密封待实测；几何通过不等于实物强度通过。先做短螺纹配合样件，再决定打印方向和预紧程度。未拼板、未发送打印。

入口mold.scad按FEATURE导出，assembly-preview.scad是完整总装，print-quantities.json是实际打印数量。
