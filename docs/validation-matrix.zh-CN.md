# 乒乓智配首版验收矩阵

这是训练/实验样机的可复核验证清单。通过某一项只说明该项在当前机械、光学和阈值配置下可记录，不代表比赛级准确率或跨球网型号兼容性。

每项当前主机覆盖、具体测试函数和实物缺口见 [`validation-coverage-v0.1.zh-CN.md`](validation-coverage-v0.1.zh-CN.md)。

| 编号 | 场景 | 操作/输入 | 预期证据 | 状态 |
| --- | --- | --- | --- | --- |
| M-01 | 内置支架重复安装 | 同一球台边缘用左右支架拆下、重新从桌下夹紧 10 次 | 上下接触面完整，M8 旋钮行程足够，左右立柱安装位置/滑移记录可复核 | 待实物 |
| M-02 | 免打孔传统桌下夹持 | 用与目标球台相同厚度的样块，从松开到夹紧完整操作 | 固定 C 形夹体跨过台边，M8 螺杆只在台面下方顶可动压块且不碰穿台面；上夹板/台底软垫不损伤台面，立柱不明显倾斜，螺杆/旋钮无卡滞或脱落 | 待实物 |
| M-03 | 替换式球网基准 | 安装左右支架、网顶承载条、真实网布、PVDF 座、STG-120ML 外托架和中央桥 | 网顶为 `152.5 mm` 首轮基准，左右立柱/两段光纤头平行，网布张力不明显拉偏支架，3.87 mm 光点机械基准可复核 | 待实物 |
| B-01 | 正常过网 | 球命中一个或多个光栅通道，无 PVDF 触发 | `clean_over`，`beam_mask`、高度区间、时间戳完整 | 主机测试 |
| B-02 | 擦网后过网 | PVDF 触发后在窗口内命中光栅 | `touch_over`，左右峰值/能量和可由 `waveform_ref` 查到的原始帧保留 | 主机测试 |
| B-03 | 擦网未过网 | PVDF 触发，窗口内无光栅 | `touch_no_cross`，`beam_mask=0`，质量标记说明无光栅 | 主机测试 |
| B-04 | 左片单独触发 | 仅通道 0 触发 | `sensor_mask=1`，事件可归并 | 主机测试 |
| B-05 | 右片单独触发 | 仅通道 1 触发 | `sensor_mask=2`，事件可归并 | 主机测试 |
| B-06 | STG 输出自检 | 按卖家确认的输出形态逐段/逐点遮挡或读取模拟量 | 只有输出语义被证实后才记录通道/点位；否则记录为接口未确认，不生成高度 | 主机测试/待实机 |
| B-07 | STG 错位/遮挡 | 断开放大器、偏移光纤头、遮挡网体或制造环境光干扰 | 自检失败或 `unknown`，不伪造高度；保留放大器诊断和机械对准记录 | 主机业务测试/待实机 |
| B-08 | 启动自检 | 上电后检查两套放大器、电源和隔离/电平接口 | 每个已确认输出通道得到 pass/fail 与校准版本；未确认输出保持 pending | 待固件接板 |
| B-09 | GPIO 队列溢出 | 人为制造高频边沿或 ISR 队列满 | 采集器复位，下一事件为 `unknown` 并带 `sensor_queue_overflow` | 主机状态测试/待实机 |
| S-01 | PVDF 波形 | 安静、轻触、擦网三类输入 | ADC1 16 kHz，20 ms 前触发 + 80 ms 后触发，可复核波形 | 主机窗口测试/待接板 |
| S-03 | ADC 波形超时 | 只收到单通道或中途停止 ADC 流 | 释放采集状态，保留不完整帧，事件带 `waveform_incomplete` | 主机测试/待接板 |
| S-02 | 机械误报 | 旋钮操作、碰夹具、球网振动 | 记录峰值/能量/持续时间，阈值调节有依据 | 待接板 |
| T-01 | 断链缓存 | 断开 WebSocket 后产生事件 | 最近事件进入 RAM 小环形缓存 | 主机测试/待接板 |
| T-02 | 恢复补发 | 恢复 WebSocket | 按事件顺序补发，事件 ID 不变，不重复生成；发送失败后事件仍保留 | 主机适配测试/待接板 |
| T-03 | 外部回放关联 | 用海康威视等外部设备时间轴对照 | `timestamp_us` 可作为后续回放关联依据 | 待联调 |
| E-01 | 单球分离 | 快速但可分离的连续单球 | 每球最多一个 `NetEvent`，不把安静间隔内的同一球拆开 | 主机测试/待实机 |

## 阶段门

- 阶段 A：文档、JSON Schema、主机状态机测试通过；
- 阶段 B：OpenSCAD 参数断言通过，并完成无 OpenSCAD 环境下的几何预览静态校验；
- 阶段 C：打印件实测项目全部由照片、量具读数和安装记录补证；
- 阶段 D：ESP-IDF 工程在目标板和最终引脚表确认后编译烧录；
- 阶段 E：至少完成 B-01～B-08、S-01～S-02、T-01～T-03、E-01 的实机记录。
