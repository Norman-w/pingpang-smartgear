## 当前验证入口

```text
python3 hardware/cad/validate_net_stand.py
python3 hardware/cad/export_net_stand_printables.py --clean
python3 hardware/cad/build_print_platter.py --preset x1c-256 --clean
python3 hardware/cad/test_preview_consistency.py
python3 hardware/electronics/validate_system_fit.py
```

`validate_net_stand.py` 负责 OpenSCAD 参数探针、左右镜像、当前打印件编译/包络、整根立柱与 C 夹接触/装配合同、网布过道/U 夹/单一内嵌止挡且无穿钉合同、桌下免打孔路径以及组合诊断件。`validate_system_fit.py` 负责原生 KiCad 板框/安装孔/3D 模型、电子腔 AABB/布尔干涉、M6 载板竖放包络、Atopile/原理图和当前 `33` 件打印包摘要。

## 证据边界

- “KiCad 文件存在”证明板框、器件占位和接口可审查，不证明铜箔已经完成或可直接下 Gerber 生产单。
- “Atopile validate/build 通过”证明接口合同可解析，不替代原理图 ERC、PCB DRC、上电和波形。
- “STL watertight、拼盘 0 超尺寸”证明封闭几何和矩形排版，不证明首层、切片、打印强度或实际安装。
- “盒盖水密”在本项目中只表示盖合后无明显开缝/错台/松动，不是防水等级认证。

现场放行统一使用 [`validation-matrix.zh-CN.md`](validation-matrix.zh-CN.md) 和 [`field-validation-record-template.zh-CN.md`](field-validation-record-template.zh-CN.md)。没有照片、量具、示波器/逻辑分析仪或真实事件日志时，状态保持 `pending`。
