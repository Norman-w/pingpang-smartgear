# 🏓 乒乓智配实施计划（zh-CN）

> 目标：做出一个可以夹在球网左右立柱边缘、带高度刻度和参考线，并能智能识别乒乓球过网高度的训练/比赛辅助设备。

## 🧭 0. 当前决策合同

- 🎯 **首个交付**：完成“安装 → 标定 → 识别 → 输出测量结果”的最小闭环。
- 📏 **默认测量定义**：测量乒乓球球心穿过球网平面时的高度 `h_cross`。
- 🏋️ **首版场景**：训练和研发验证优先；暂不作为正式比赛裁判依据。
- 👁️ **识别路线**：先用单相机和录制视频做离线验证，再决定是否需要双相机、深度传感器或专用硬件。
- 🧩 **机械路线**：左右夹具、可调延长杆、刻度和参考线先独立验证，不把机械结构绑定到某个相机型号。
- 🛑 **暂不锁定**：球网立柱规格、相机型号、主控平台、最终外观和量产材料，等实测数据后确定。

## 📐 P0：现场测量与需求冻结

### 目标

先把设备需要夹住什么、不能碰什么、测量结果到底代表什么确定下来。

### 任务清单

- [ ] 📏 记录目标球网立柱的外径、截面形状、材质和可夹持长度；
- [ ] 📏 记录球桌台面、球网、网架调节件和相邻空间的尺寸；
- [ ] ⚠️ 标记不能遮挡、不能受力或容易干涉的位置；
- [ ] 🧪 确认参考线高度的调节范围和最小刻度；
- [ ] 🧭 确认相机可安装的位置、视角和允许的拍摄区域；
- [ ] 📝 冻结 `h_cross`、`h_ref`、`delta_h` 和 `unknown` 的定义。

### 交付物

- `hardware/measurements/net-post-survey.md`：现场尺寸记录；
- `docs/decisions/`：关键设计决策记录；
- 一张带尺寸的球网、立柱和相机相对位置草图。

### 验收标准

- 至少有一套真实球网立柱的完整尺寸；
- 能明确说明夹具的受力位置和禁止干涉区域；
- 任意一条测量结果都能解释“相对于哪个平面、哪个高度基准”。

## 🛠️ P1：机械基准原型

### 目标

不依赖智能识别，先做出能稳定安装和重复读数的机械装置。

### 任务清单

- [ ] 🧱 设计左右夹具的夹紧面、保护垫和锁紧方式；
- [ ] 🪜 设计延长杆的调节、锁定和防旋转结构；
- [ ] 🔢 设计面向操作者和相机的高度刻度；
- [ ] 🧵 设计参考线的端部连接、张力和快速更换方式；
- [ ] ⚖️ 设计左右同刻度的校准和水平检查方法；
- [ ] 🖨️ 先用纸板、木料或 3D 打印件完成低成本打样；
- [ ] 🧪 记录安装重复性、滑移、变形和对球网张力的影响。

### 交付物

- 参数化 CAD 或尺寸草图；
- 第一版 BOM；
- 机械原型照片和装配记录；
- `hardware/` 下的版本化零件与装配说明。

### 验收标准

- 单人可以快速完成左右安装和拆卸；
- 参考线在目标调节范围内可以稳定拉直；
- 重复安装后左右同高误差达到初始目标（暂定 ≤ 1 mm，以实测修订）；
- 不损伤立柱，不明显改变球网正常张紧状态。

## 🎯 P2：标定与测量基准

### 目标

建立从机械刻度、参考线到图像/传感器坐标的可追溯关系。

### 任务清单

- [ ] 🧭 明确球网平面 `x = 0` 的标定方法；
- [ ] 📍 设计已知高度标记或标定板；
- [ ] 📷 测试不同相机距离、焦距和俯仰角下的误差；
- [ ] 📏 建立像素坐标到毫米高度的映射；
- [ ] 🧪 用静止球、已知高度目标和多次安装做重复性测试；
- [ ] 🚦 定义标定失效条件和 `unknown` 输出条件。

### 交付物

- 标定流程和操作界面/脚本；
- 标定数据格式与版本号；
- 一组可复现的静态测量测试数据；
- 测量误差与重复性报告。

### 验收标准

- 能在重新安装后完成标定并恢复有效状态；
- 标定数据中包含时间、设备、参考高度和质量信息；
- 首版视觉测量目标误差暂定为 ≤ 5 mm，需用实测结果确认或调整。

## 👁️ P3：离线视觉 MVP

### 目标

先证明普通相机能够在真实球路中稳定找到球网平面处的球心高度。

### 任务清单

- [ ] 🎞️ 建立录制视频和标注数据集；
- [ ] 🟢 检测乒乓球并跟踪短时轨迹；
- [ ] 🧵 区分球、参考线和球网背景；
- [ ] 📈 对球路进行插值或外推，估计 `x = 0` 时的高度；
- [ ] 🧮 计算 `h_cross`、`h_ref`、`delta_h`；
- [ ] 🚫 处理遮挡、运动模糊、反光、丢帧和多球干扰；
- [ ] 📤 输出带置信度和质量标记的 JSON 事件；
- [ ] 🔍 保存关键帧和中间结果，保证结果可复核。

### 交付物

- `vision/` 下的离线处理工具；
- 最小数据集和标注说明；
- 一组输出事件示例；
- 误检、漏检和 `unknown` 的统计报告。

### 验收标准

- 能处理一段真实训练视频并输出有意义的过网事件；
- 识别失败时输出 `unknown`，不把无效结果伪装成 0；
- 每条结果都能回溯到视频时间点、标定版本和质量标记。

## 🔌 P4：集成式设备原型

### 目标

把机械基准、采集设备、识别程序和结果接口组成一个可重复使用的原型。

### 任务清单

- [ ] 🔩 设计相机、补光或传感器安装件；
- [ ] 🔋 确认供电、连接方式和现场部署流程；
- [ ] 📡 确定设备与电脑、手机或训练系统的通信接口；
- [ ] 🧭 实现安装检查、标定、准备、采集、结果和故障状态；
- [ ] 📦 保存设备配置、标定记录和测量事件；
- [ ] 🔁 进行不同球速、旋转、背景和光照条件测试。

### 验收标准

- 按说明书可重复完成安装和标定；
- 设备能明确显示“可以测量/不可测量”；
- 结果接口与 `docs/architecture.md` 中的 schema 保持兼容；
- 现场失败时可以恢复，不需要重装整个工程。

## 🏆 P5：训练与比赛辅助扩展

### 目标

在测量闭环稳定后，扩展到训练反馈和比赛场边辅助，而不是提前把 MVP 做成庞杂系统。

### 可能方向

- 📊 过网高度趋势、落点和回合统计；
- 🔔 超过或低于目标高度的即时提示；
- 🧑‍⚖️ 比赛场边的可复核事件记录；
- 🔗 与 `smartpaddle / 乒云`、智能球桌或识别系统对接；
- 🧰 多球桌配置、快速校准和设备健康检查；
- 🏷️ 设备编号、校准有效期和版本追踪。

### 进入条件

- P4 的机械安装重复性和测量质量达到可接受水平；
- 识别结果带有足够的质量标记；
- 已明确训练提示和比赛辅助之间的产品边界。

## 🧪 测试策略

### 单元/离线测试

- 📐 坐标变换、标定和高度计算；
- 🎯 已知高度目标的误差；
- 👁️ 球检测、轨迹拟合和遮挡处理；
- 📦 JSON schema 和版本兼容性。

### 台架测试

- 🛠️ 夹具承载、滑移、旋转和重复安装；
- 🧵 参考线张力对左右高度的影响；
- 📷 相机距离、角度、光照和背景变化；
- 🔋 供电、通信和长时间运行。

### 场景测试

- 🏓 不同球速、旋转、弧线和过网高度；
- 🌗 室内强光、背光、反光和复杂背景；
- 👥 单人训练、多球和多人干扰；
- 🏆 训练场与比赛场边的快速部署。

## ⚠️ 主要风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 立柱规格差异大 | 夹具无法通用 | 参数化夹具、可换夹爪、先建立尺寸样本 |
| 球网遮挡乒乓球 | 高度误差或漏检 | 高对比标记、调整视角，必要时双视角 |
| 参考线被拉偏 | 高度基准失效 | 防旋转结构、左右锁定、安装自检 |
| 运动模糊和光照变化 | 识别不稳定 | 快门、补光、多帧跟踪，低质量时输出 unknown |
| 过早锁定硬件平台 | 返工成本高 | 先离线验证接口，再选相机和主控 |
| 训练结果被误当裁判结果 | 使用风险 | 明确产品文案、质量标记和比赛验证边界 |

## 📌 下一步执行顺序

1. 📏 获取一套真实球网立柱和球桌的尺寸；
2. 📝 完成 P0 的现场测量记录；
3. 🧱 用低成本材料做夹具与延长杆验证件；
4. 🎞️ 同步录制第一批侧视或斜视训练视频；
5. 👁️ 开始 P2/P3 的标定和离线视觉验证；
6. 🔁 根据实测结果回写本计划和硬件参数。

## 🗂️ 版本与提交约定

- 计划变更使用中文提交说明，并保持每个阶段可独立回滚；
- 机械尺寸、标定数据和识别 schema 都要带版本；
- 每完成一个阶段，补充验收记录和已知限制；
- 任何“看起来能用但无法复核”的结果都标记为 `unknown` 或实验数据。
