# M6 45° L 型十路检测器铝合金加工输入 v0.7

状态：`当前冻结主体和传感器姿态；壳体已按 x 光学端/线缆端分段完成装配候选，待主体首件和真实接口放行`。

权威几何是 [`hardware/cad/net_stand.scad`](../hardware/cad/net_stand.scad)。机器可读的尺寸、数量和源文件哈希由 [`hardware/cad/export_m6_machining_spec.py`](../hardware/cad/export_m6_machining_spec.py) 生成。

## 1. 当前结构

左右各一套，光学轴和 M6 外丝轴沿 `x`，每套 10 个通道，中心高度为球台上方 `+10…+190 mm`，节距 `20 mm`。M6 L 型器件的出光/受光面水平朝球台中心，蓝色护套/尾线局部朝 `z-`，整件绕光束轴 `x` 旋转 `-45°`；器件从各自外侧沿 `x` 穿入主体，尾线向 `y-/z-` 让开相邻器件。后侧浅六角窝只负责防止真实金属六角晃动，不把六角与外丝接驳平面埋掉；M6 外丝直接穿过主体，预览中金色螺帽表示主体外表面的一枚原配螺帽，右侧外侧为 `x+`、左侧镜像为 `x-`。

主体是连续的 `6061-T6` 长条铝件：

| 项目 | 当前名义值 |
| --- | ---: |
| 中央长条基准包络（x × y × z） | `10 × 56 × 216 mm` |
| 含一体 T 尾座的加工毛坯包络 | `20 × 69.2 × 216 mm`；尾座与中央长条在 y 方向重叠 `0.8 mm` |
| 主体全局下沿/上沿 | `z=144.5…360.5 mm` |
| 水平 M6 外丝段 | `M6×0.75`，名义长度 `14 mm` |
| 光学头到外丝末端总包络 | 名义 `20 mm` |
| 一枚原配螺帽高度占位 | `5 mm` |
| 主体允许最大厚度 | `14 + 2 − 5 − 1 = 10 mm`（含 2 mm 头部卡入） |
| 当前主体厚度余量 | `10 − 10 = 0 mm`（名义值；螺帽真实厚度和有效外丝需首件复核） |
| 水平 M6 通孔 | `Ø6.6 mm`，沿 x 贯穿，略大于外丝 |
| 尾线让位 | 蓝色护套/线缆局部 z−，随 x 轴 `-45°` 滚转后向 y−/z− |
| 后方浅六角窝 | AF `8 mm`，沿 x 深 `2.1 mm`，底部保留 `0.8 mm`；只卡住真实 AF8 六角，不埋住六角/外丝接驳平面 |
| 一体 T 尾座 | y− 外侧深 `14 mm`、高 `28 mm`，向本侧 x 外伸 `10 mm`；全局 `x=761.25…781.25`、`y=-41.2…-27.2`、`z=238.5…266.5 mm` |
| 尾座 M8 内丝 | `M8×1.25`；x 向有效啮合 `12 mm`，预钻/攻牙底孔 `Ø6.8 mm`，入口沉台 `Ø9.5×1 mm` |

不采用旧版左右交错托舌；当前是单列竖直安装，全部光学中心和主体中心都在 `y=0`。主体高度由 10 个 `20 mm` 间距通道和上下各 `18 mm` 边框余量决定。线缆不在铝主体里挖槽，统一套管从底盖开放孔引出。

## 2. 分体壳与线缆（装配候选，不是最终打印放行项）

主体外面使用 PETG 非承力保护壳；当前壳体已经按真实方向和总成接口建出候选，待主体首件验收后按实际六角、45°尾线和球头接口冻结：

- 从 `z+` 俯视，前盖位于 `x-` 光学端，外形为正圆弧；后盖位于 `x+` 线缆端，外形为圆角矩形，并在 `y-` 侧为一体铝合金 T 尾座让位；中间只表示前后盖分型边界，不建连线；M8 外牙直接沿 x 进入铝合金尾座内丝；
- 前后盖均从主体 `z+` 套入，主体 `y±` 两侧的连续竖直槽由前盖、后盖分别占用 `x-` / `x+` 半段，槽/舌负责定位，沉头螺钉负责固定；
- 底盖按下方截面盖住壳体，使用两枚沉头螺丝固定，中央开放 `Ø12 mm` 过孔供剥皮后的统一线缆套管通过；该孔没有密封设计。

PETG 盖件不作为承力件；承力路径应是“传感器六角/铝主体 → 一体 T 形尾座 M8 内丝 → 金属 M8 外牙球头 → 90°金属支撑 → 竖直球头/网夹适配板 → 网架”。

## 3. 铝件加工清单

每侧 3 种铝/金属件各 1 件，两侧共 6 个机加工预览 STL：

| `PART` | 局部包络 | 作用 |
| --- | ---: | --- |
| `m6_machining_detector_body` | `20 × 69.2 × 216 mm`（中央基准 `10 × 56 × 216 mm`） | 十路 20 mm 节距光学让位孔、十路 45° L 型安装孔、浅六角防转窝、一体 T 尾座和盖件预留孔；右侧 x+、左侧 x- 外侧装入，M8 内丝直接加工在尾座 |
| `m6_machining_support` | `106.75 × 18 × 60 mm` | 水平承托臂、竖直腿、两侧三角加固肋；90° 金属承力路径 |
| `m6_machining_adapter` | `6 × 56 × 228 mm` | 竖直网夹/立柱适配板；当前显示与支撑腿的横向连接孔 |

`m6_machining_detector_body` 和 `m6_machining_support` 的局部原点均为各自包络的 x/y/z 最小点；适配板保持 x-min、y 中心线、z-min 的传统板件坐标。采购球头不进入铝件 STL。

## 4. 竖直采购球头接口

当前视觉占位使用 `13mm球【M8外牙】`，球头本体保持竖直：下方螺柱接金属 90° 支撑，侧向 M8 外牙直接拧入铝合金一体 T 尾座；后盖仅让位，不承受球头弯矩。可选采购项保留：

```text
13mm球【1/4内牙】
13mm球【1/4外牙】
13mm球【3/8外牙】
13mm球【M6外牙】
13mm球【M8外牙】
13mm球【M10外牙】
```

选项只改变球头一侧的转接螺纹/紧固件，不改变十路铝主体；下单前必须实测球头螺纹所在端、有效长度、旋钮净空、球头直径和开口姿态。

## 5. 首样顺序

1. 用真实 M6 器件验证头部六角 AF、水平总包络、14 mm 外丝段、有效外丝、原配螺帽、光学中心和尾线出口。
2. 先做主体单孔/单件试装，确认 `10 mm` 名义厚度和浅六角窝能让 M6 外丝穿出，并由朝台内平滑面的一枚原配螺帽锁紧；确认光学/外丝轴水平朝球台中心，蓝色尾线先朝 z−、再绕 x 轴 `-45°` 让线。
3. 加工一根完整十路主体，逐孔检查 `+10…+190 mm` 高度、`20 mm` 节距、x 光轴平行度、两侧外向插入、尾线和相邻通道净空，再镜像加工另一侧。
4. 主体验收通过后，按真实器件和金属固定器接口冻结前盖、后盖、底盖；当前候选壳体可用于装配检查，但不作为打印放行件。
5. 到货后把球头装成竖直姿态，确认金属固定器、90°支撑、竖直适配板和真实网夹能形成连续承力路径。

