# M6 45° L 型十路检测器 PETG 首样 / CNC 复用输入 v0.8

状态：`当前冻结主体和传感器姿态；壳体已按 x 光学端/线缆端分段完成装配候选，待主体首件和真实接口放行`。

权威几何是 [`hardware/cad/net_stand.scad`](../hardware/cad/net_stand.scad)。机器可读的尺寸、数量和源文件哈希由 [`hardware/cad/export_m6_machining_spec.py`](../hardware/cad/export_m6_machining_spec.py) 生成。

## 1. 当前结构

左右各一套，光学轴和 M6 外丝轴沿 `x`，每套 10 个通道，中心高度为球台上方 `+10…+190 mm`，节距 `20 mm`。M6 L 型器件的出光/受光面水平朝球台中心，蓝色护套/尾线局部朝 `z-`，整件绕光束轴 `x` 旋转 `-45°`；器件从各自外侧沿 `x` 穿入主体，尾线向 `y-/z-` 让开相邻器件。后侧浅六角窝只负责防止真实金属六角晃动，不把六角与外丝接驳平面埋掉；M6 外丝直接穿过主体，预览中金色螺帽表示主体外表面的一枚原配螺帽，右侧外侧为 `x+`、左侧镜像为 `x-`。

主体当前先按可打印 PETG 长条首样冻结；后续可以沿同一包络改做 CNC/金属版本：

| 项目 | 当前名义值 |
| --- | ---: |
| 中央长条基准包络（x × y × z） | `10 × 56 × 216 mm` |
| 后盖背面中央加厚 boss 包络 | `14 × 18 × 36 mm`；与 x+ 后盖在 x 方向重叠 `3 mm`，全局约 `x=782.4…796.4`、`y=-9…9`、`z=234.5…270.5 mm`；左侧发射端按 x 镜像 |
| 主体全局下沿/上沿 | `z=144.5…360.5 mm` |
| 水平 M6 外丝段 | `M6×0.75`，名义长度 `14 mm` |
| 光学头到外丝末端总包络 | 名义 `20 mm` |
| 一枚原配螺帽高度占位 | `5 mm` |
| 主体允许最大厚度 | `14 + 2 − 5 − 1 = 10 mm`（含 2 mm 头部卡入） |
| 当前主体厚度余量 | `10 − 10 = 0 mm`（名义值；螺帽真实厚度和有效外丝需首件复核） |
| 水平 M6 通孔 | `Ø6.6 mm`，沿 x 贯穿，略大于外丝 |
| 尾线让位 | 蓝色护套/线缆局部 z−，随 x 轴 `-45°` 滚转后向 y−/z− |
| 后方浅六角窝 | AF `8 mm`，沿 x 深 `2.1 mm`，底部保留 `0.8 mm`；只卡住真实 AF8 六角，不埋住六角/外丝接驳平面 |
| 后盖 boss 球头孔 | `Ø8.6 mm`，沿 `x` 向 `x-` 贯入 `14 mm`；当前为 M8 外牙通孔，实际承力由采购金属球头和到货件配合确认 |
| 采购球头接口 | 13 mm 球，当前默认 `M8 外牙`；球头保持竖直，横向 M8 外牙从各自 x 后端插入背面中央 boss，z− 竖直接口由采购金属 90°连接器从最低端承接，再以两枚 M6 贯穿螺栓连接网夹立柱 |

不采用旧版左右交错托舌；当前是单列竖直安装，全部光学中心和主体中心都在 `y=0`。PETG 首样主体高度由 10 个 `20 mm` 间距通道和上下各 `18 mm` 边框余量决定，后续 CNC 沿用同一包络。线缆不在主体里挖槽，统一套管从底盖开放孔引出。

## 2. 分体壳与线缆（装配候选，不是最终打印放行项）

主体外面使用 PETG 非承力保护壳；当前壳体已经按真实方向和总成接口建出候选，待主体首件验收后按实际六角、45°尾线和球头接口冻结：

- 从 `z+` 俯视，前盖位于 `x-` 光学端，外形为正圆弧；后盖位于 `x+` 线缆端，外形为圆角矩形，并在 x+ 背面中央（y=0、z 中心）形成加厚 boss；中间只表示前后盖分型边界，不建连线；采购球头 M8 外牙沿 x 进入 boss 通孔；
- 前后盖均从主体 `z+` 套入，主体 `y±` 两侧的连续竖直槽由前盖、后盖分别占用 `x-` / `x+` 半段，槽/舌负责定位，沉头螺钉负责固定；
- 底盖按下方截面盖住壳体，使用两枚沉头螺丝固定，中央开放 `Ø12 mm` 过孔供剥皮后的统一线缆套管通过；该孔没有密封设计。

PETG 壳体负责保护和定位；首样承力路径按“传感器六角/主体 → 后盖加厚 boss（必要时增加金属嵌件或 CNC 版本）→ 采购 13 mm 球头 → 球头 z− 接口 → 采购金属 90°连接器 → 两枚 M6 贯穿螺栓 → 商品网夹/网架”验证。90°连接器是外购金属承力件，不由 PETG 壳体代替。

## 3. 首样与机加工复用清单

每侧打印主体/盖件各一套；机加工预览只保留主体包络，采购球头不导出 STL：

| `PART` | 局部包络 | 作用 |
| --- | ---: | --- |
| `m6_machining_detector_body` | `10 × 56 × 216 mm` | 十路 20 mm 节距光学让位孔、十路 45° L 型安装孔、浅六角防转窝和盖件预留孔；右侧 x+、左侧 x- 外侧装入，主体保持简单矩形 |

`m6_machining_detector_body` 的局部原点为包络 x/y/z 最小点；后盖 boss、前后盖和底盖由完整 PETG 组件预览单独导出。采购球头和商品网夹不进入 STL。

## 4. 竖直采购球头接口

当前视觉占位使用 `13mm球【M8外牙】`，球头本体保持竖直：横向 M8 外牙从 x 后端进入后盖背面中央加厚 boss；球头 z− 接口向下，由采购金属 90°连接器从最低端承接，连接器从接口最低端向上到网夹立柱孔中心，当前基准高度为 `49 mm`，再用两枚 M6 贯穿螺栓固定到网夹立柱。可选采购项保留：

```text
13mm球【1/4内牙】
13mm球【1/4外牙】
13mm球【3/8外牙】
13mm球【M6外牙】
13mm球【M8外牙】
13mm球【M10外牙】
```

选项只改变球头一侧的转接螺纹/紧固件，不改变十路 PETG 主体；下单前必须实测球头螺纹所在端、有效长度、旋钮净空、球头直径和开口姿态。

## 5. 首样顺序

1. 用真实 M6 器件验证头部六角 AF、水平总包络、14 mm 外丝段、有效外丝、原配螺帽、光学中心和尾线出口。
2. 先做主体单孔/单件试装，确认 `10 mm` 名义厚度和浅六角窝能让 M6 外丝穿出，并由朝台内平滑面的一枚原配螺帽锁紧；确认光学/外丝轴水平朝球台中心，蓝色尾线先朝 z−、再绕 x 轴 `-45°` 让线。
3. 加工一根完整十路主体，逐孔检查 `+10…+190 mm` 高度、`20 mm` 节距、x 光轴平行度、两侧外向插入、尾线和相邻通道净空，再镜像加工另一侧。
4. 主体验收通过后，按真实器件和金属固定器接口冻结前盖、后盖、底盖；当前候选壳体可用于装配检查，但不作为打印放行件。
5. 到货后把球头装成竖直姿态，确认横向 M8 外牙与后盖 boss 同轴、z− 接口最低端与金属 90°连接器套筒同轴、连接器两枚 M6 孔与网夹立柱槽孔重合，并检查球头锁紧后的微调保持性。
