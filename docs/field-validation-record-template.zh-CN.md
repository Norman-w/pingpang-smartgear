# 乒乓智配实物验证记录模板

本模板用于把打印件、光学模块、PVDF 前端、ESP32-S3 固件和 SmartPaddle 连接层的实测证据留档。没有照片、量具读数、原始波形或事件日志时，项目状态保持“待实物”，不以主机测试代替实体验收。

建议文件名统一为：`<记录编号>-<测试编号>-<序号>.<ext>`，例如 `run-01-B06-03.json`、`run-01-S01-left-raw.csv`、`run-01-M03.jpg`。

也可以使用 [`field-validation-record.example.json`](field-validation-record.example.json)
作为机器可校验的记录起点。运行
`python tools/validate_field_record.py <记录文件>.json` 会要求全部 M/B/S/T/E
编号都存在；`pass`/`fail` 必须绑定 `evidence_root` 下真实存在的证据文件，只有
`pending` 才允许暂时没有证据。模板记录默认全部为 `pending`，不代表实机通过。

## 1. 机械与标定记录

### M-01 重复安装

1. 在同一 Ø25 mm 立柱上标记固定参考点。
2. 松开、侧向安装、旋钮夹紧、测量夹具参考点；重复 10 次。
3. 每次记录安装位置、拆装后位置差、旋钮圈数/手感和软垫状态。

| ---: | ---: | ---: | --- | --- |
| 1…10 |  |  |  |  |

### M-02 X 夹具运动

记录 10°、15°、20° 以及实际旋钮行程。检查两根活动臂是否卡滞、Ø8 mm 中心轴是否松脱、竖直滚柱与压盖是否防脱、螺杆圆头是否落入圆坑。出现裂纹、明显永久变形或夹不住立柱时判定失败，并保留照片。

### M-03 双侧基准

安装左右夹具、12×12 mm 方杆、固定桥件、连续光栅导轨和参考线。用直尺/水平仪记录两侧杆平行度、网顶到光栅基准高度、参考线是否只能停在 10 mm 档位，以及拉线张力是否使夹具转动。

## 3. 业务、链路与回放记录

### E-01 单球场景

至少记录正常过网、擦网后过网、擦网未过网，以及快速但可分离的连续单球。检查每球事件数、状态、时间戳、光束位图、擦网传感器位图和质量标记；重叠多球不在首版验收范围内。

### T-01/T-02 断链与补发

在 WebSocket/既有连接层断开期间制造事件，记录断开前后的事件 ID、RAM 缓存数量和发送失败结果；恢复连接后记录补发顺序、重复数、剩余缓存和 App 接收日志。发送失败的事件必须仍可恢复。

### T-03 外部视频关联

使用同一时钟来源或记录时钟偏移，将 `timestamp_us` 与外部视频/设备时间轴对照。这里仅验证后续回放关联能力，不把相关性记录解释为视觉裁判结论。
