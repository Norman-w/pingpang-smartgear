# 乒乓智配当前支架可视核验记录 v0.1

本文记录当前 `hardware/cad/net_stand.scad` 的人工可视核验范围和结论。它证明的是 OpenSCAD 装配关系在渲染图中可读，不替代 PETG 实物强度、标准件装配、光学对准或球台现场验收。

## 可复现入口

```text
python3 hardware/cad/render_net_stand_preview.py \
  --output-dir /tmp/pingpang-smartgear-render
python3 hardware/cad/render_m6_views.py \
  --part m6_detector_mount \
  --output-dir /tmp/pingpang-smartgear-render/m6-audit
python3 hardware/cad/render_m6_views.py \
  --part m6_detector_exploded \
  --output-dir /tmp/pingpang-smartgear-render/m6-audit
python3 hardware/cad/export_m6_component_previews.py \
  --clean \
  --output-dir /tmp/pingpang-smartgear-render/m6-component-previews
```

CI 也会在 `OpenSCAD geometry validation` job 中生成并上传当前支架和历史外挂 X 夹具的 PNG artifact。当前支架的渲染脚本输出包括整体装配、左右支架、桌下夹持剖面、斜立柱下段/上段与固定夹体共面落座、立柱与固定基台的爆炸/截面、网布过道与 Ø10 圆柱插杆侧开接收腔爆炸/截面、M6 检测器总成/无剖切爆炸图、M6 各单件、PVDF 座；专用 `render_m6_views.py` 还为总成和爆炸图各输出 x-/x+/y-/y+/z-/z+ 六视图及等轴视图。旧 STG-120ML 托架和标定规仍单独渲染用于历史回归，不作为当前采购件结论。

## 结论边界

- 当前 CAD 的装配方向、镜像关系、免打孔夹持路径、M6 x 轴光学方向、20 mm 十路 PETG 主体、前后盖分体和后盖 boss/采购球头接口已通过可视核验及自动几何回归。
- M6 总成爆炸图使用完整实体，不使用剖切；“前盖更大且遮住激光头/单枚螺帽”的结论只针对当前 CAD 包络，仍须按真实 SKU 首件复核。
- 后盖 boss 在 STL 中以 `Ø7.0 mm` x 向 1/4-20 外牙通孔和隐藏捕获螺母窝表示，boss 根部另以 y± 两条避开中央孔的实体桥接肋连接到后壳侧壁；实际螺纹/金属承力件由采购球头与标准螺母提供；斜立柱下段/上段的分型面连接、四个 M3 孔和顶部 M8 支撑孔分别保留在对应打印件中，M6 下端独立支撑尚待定义；主体、前后盖和底盖都是 PETG 首样候选，后续主体/boss 可改 CNC 或加金属嵌件。
- 独立组件导出包包含左右各一套主体、前盖、后盖、底盖，共 8 个完整 STL；正式网架打印包另含左右各一根 Ø10×152.5 mm `net_clamp_rod`，平放打印后沿原门洞轴线从 x 侧装入下段侧开接收腔；采购球头、网布和标准金属件不进入打印 STL。M6 总成和无剖切爆炸图各有 7 张视图（六视图 + 等轴），方向箭头为审计叠加，不进入零件 STL。
- 渲染图不能证明支架在目标球台上夹得住，也不能证明 PVDF 或红外光栅已经有有效电气信号。
- `docs/field-validation-record.example.json` 中的 M/B/S/T/E 现场项目继续保持 `pending`，在没有照片、量具/示波器记录、原始波形和真实事件日志前不改为 `pass`。
