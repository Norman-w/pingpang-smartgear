# 首个原型：球网立柱夹持式过网高度检测设备

## 1. 目标

做一个可以快速夹在球网左右立柱边缘的可调式装置：

1. 两侧夹具不改变球网正常张紧方式，不损伤球网立柱；
2. 两侧向上延伸，并提供清晰、可重复读取的高度刻度；
3. 在左右延长杆相同刻度处拉设参考线；
4. 通过相机或其他传感器识别乒乓球经过球网平面时的高度；
5. 输出过网高度、相对参考线的高度差和识别置信度。

## 2. 测量定义

首版统一使用以下概念，避免“过网高度”在机械、视觉和训练记录中含义不一致：

- **球网平面**：球网所在的竖直参考平面，记为 `x = 0`；
- **高度轴**：垂直于球桌台面的方向，记为 `z`；
- **过网高度** `h_cross`：乒乓球球心穿过 `x = 0` 时的高度；
- **参考高度** `h_ref`：两侧延长杆和参考线共同定义的高度；
- **高度差** `delta_h`：`h_cross - h_ref`；
- **识别结果**：`above`、`below` 或 `unknown`，其中 `unknown` 用于遮挡、模糊、未标定等情况。

如果后续训练需要测量球的底部、顶部或球拍击球点，应新增明确字段，不复用 `h_cross`。

## 3. 最小可行原型（MVP）

### M0：机械基准件

- 左右各一个夹持模块；
- 可调高度的延长杆；
- 毫米级刻度或可打印刻度贴；
- 可拆卸参考线；
- 左右同刻度锁定和水平/垂直检查方法。

### M1：可视化测量

- 固定相机位置和拍摄区域；
- 用已知高度标记完成标定；
- 检测乒乓球并估计球心轨迹；
- 估计球心在球网平面处的高度；
- 与 `h_ref` 比较并输出结果。

### M2：智能设备化

- 相机或传感器模块快速安装；
- 自动检查球网平面、参考线和标定状态；
- 保存带时间戳的过网事件；
- 为 `smartpaddle / 乒云`、智能球桌或比赛辅助系统提供通信接口。

## 4. 初始工程目标（待实测修订）

这些数值是第一轮打样的目标，不是最终承诺：

| 项目 | 初始目标 |
| --- | --- |
| 安装方式 | 单手可操作的左右夹持，尽量不拆球网 |
| 调节方式 | 延长杆连续或分档调节，带机械锁定 |
| 刻度 | 1 mm 分辨率，5 或 10 mm 主刻度 |
| 参考线 | 低弹性、可视、高对比、可快速更换 |
| 左右对称误差 | 目标不超过 1 mm，需通过量具验证 |
| 识别结果 | 高度值、相对参考线差值、above/below/unknown、置信度 |
| 首版测量误差 | 以 5 mm 以内为视觉系统目标，需用标定球路实测 |

## 5. 关键设计约束

### 夹具

- 兼容不同直径、截面和材质的球网立柱；
- 不遮挡球网调节机构，不让夹具滑落到球桌台面；
- 夹紧力可控，接触面使用柔性保护层；
- 延长杆安装后不能明显改变球网或立柱的受力状态。

### 延长杆与刻度

- 左右刻度零点必须有清晰定义；
- 刻度应面向相机和操作者；
- 延长杆应有防旋转结构，否则参考线会发生空间偏转；
- 参考线的张力不能把左右夹具拉偏。

### 视觉识别

- 需要区分球网平面、参考线和乒乓球；
- 需要处理球网遮挡、背景复杂、反光和运动模糊；
- 单相机方案先验证可行性，必要时再升级双相机或深度方案；
- 每次输出必须能判断是否处于有效标定状态。

## 6. 首轮验证顺序

1. 测量常见球网立柱的直径、截面、可夹持空间和干涉位置；
2. 用纸板/3D 打印件验证夹具的夹持方式和延长杆受力；
3. 用手工刻度和参考线验证左右同高、线张力和安装重复性；
4. 固定单相机，使用静止球和已知高度目标验证像素到毫米的标定；
5. 加入运动中的球，验证过网事件检测和高度估计；
6. 再决定相机、补光、标记物、主控和通信协议。

## 7. 待确认问题

- 目标兼容的球网立柱尺寸范围是多少？
- 首版设备是优先面向训练场景，还是优先面向比赛场边快速部署？
- “过网高度”默认测球心，还是训练中需要球底部/顶部等其他定义？
- 相机是否允许固定在球桌侧面、球网立柱或独立支架上？
- 输出是否需要直接接入已有的 `smartpaddle / 乒云` 数据流？
