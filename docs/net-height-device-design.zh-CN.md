# 乒乓智配：内置式球网支架、擦网与过网高度设备

> 当前采购和接口结论以 [`docs/optical-gate-procurement-decision-v0.1.zh-CN.md`](optical-gate-procurement-decision-v0.1.zh-CN.md) v0.2 为准。本文早期的“10 路离散红外发射/接收 + 10 mm 导轨”内容已被 STG-120ML 两段光纤头方案替代；保留的旧字段只用于历史固件/状态机兼容，不代表当前硬件已经具备逐光束输出。

## 1. 当前方案与边界

当前机械方向已经从“夹在原球网立柱两侧的外挂 X 夹具”切换为“直接替换传统球网的内置式球网支架” ：

- 左右立柱、桌下夹持、网布、网顶承载条和传感器安装位组成一套完整球网支架；
- 支架像传统网架一样从球台下方夹住台面，使用上下接触面和竖直螺杆夹紧；
- 网顶 PVDF 振动监测在装配时直接安装在支架网顶，不再依赖原球网立柱上的外挂夹片；
- 左右外侧托架与中央背靠背支撑桥承载两段 STG-120ML 对射金属光纤头；每段约 `763 mm`，光纤头有效检测面约 `120 mm`、点距 `3.87 mm`；
- STG-120ML 光纤头必须配放大器，放大器型号、输出语义、工作电流和是否能给出逐点高度仍待卖家/实物确认；
- ESP32-S3 继续生成独立的 `NetEvent v0.1`，与 BLE、WebSocket、MQTT、SSE 和 App 传输解耦；
- 首版不使用相机，不判断过网方向，不处理重叠多球，不宣称正式比赛裁判能力。

尺寸、阈值、时间窗和材料是首轮样机参数。真实球台厚度、网布张力、夹持力、PVDF 贴合方式、光学距离和环境光裕量必须通过实物记录后再收敛，当前不提交最终精度承诺。

旧的外挂方案保留在 `hardware/cad/net_post_x_clamp.scad`，只作为历史设计回溯和旧几何回归；当前机械参数源是 `hardware/cad/net_stand.scad`。

## 2. 系统分层

```text
替换式球网网顶 ── 左/右 PVDF 夹片 ── AFE ── 比较器 ──┐
                                                       ├─ ESP32-S3 业务事件层
STG-120ML 两段光纤头 ── 配套放大器 ── 隔离/电平接口 ────────┘       │
                                                               ├─ RGB/蜂鸣器
                                                               ├─ SmartPaddle WebSocket 适配
                                                               └─ RAM 小环形缓存
```

BLE、Wi-Fi、WebSocket、MQTT、SSE、配网和 App 多设备基础设施不在本工程重新设计；本工程只提供传输无关的业务事件和首个适配接点。ESP32-S3 固件通过 `firmware/main/net_event_transport.h` 的连接 hook 接入 SmartPaddle 现有连接层；没有接入 hook 时保持 fail-closed，不假装已经联网。

## 3. 内置式球网支架与 OpenSCAD

### 3.1 支架主体

`hardware/cad/net_stand.scad` 是当前唯一参数源，坐标为 `x=球台宽度方向、y=球台长度方向、z=台面以上`。首轮参数：

| 项目 | 参数 |
| --- | ---: |
| 球台宽度 | `1525 mm` |
| 首轮台面厚度 | `25 mm` |
| 网顶高度 | `152.5 mm` |
| 立柱中心离台边 | `37 mm` |
| STG-120ML 检测窗口 | 约 `0…120 mm`，商品图标注 `32 × 3.87 mm` 光点 |
| 网顶 PVDF 安装座 | 左右各 1 个 |
| 桌下夹紧螺杆 | M8×1.25 竖直圆头螺杆 + 双螺母捕获旋钮 |

每侧支架由以下部分组成：

- 立柱主体：从桌下夹持区域一直延伸到最高光栅模块上方，顶部承载网顶承载条和光学导轨；为适配常见打印幅面，当前拆成两段约 `153 mm` 的立柱段，上段由 `post_segment_index=1` 导出，下段与固定 C 形夹组成 `lower_stand_segment` 一体件，接缝用 `post_joint_sleeve` 外套筒和 `post_joint_key` 内芯定位；
- 传统桌下夹持：固定 C 形夹体跨过台面边缘，上夹板通过可替换 TPU/硅胶保护垫压住台面上表面，台底可动压块由下方 M8 圆头螺杆顶起并夹紧；固定下臂捕获一枚 M8 螺母，螺杆下端再用两枚 M8 螺母预先对锁并装入打印旋钮，使旋钮与螺杆刚性同步，避免依赖 PETG 内螺纹或形成未定义的双螺纹约束；螺杆圆头只接触压块底面，始终位于台面下方，不穿过球台或压块，整个支架免打孔安装；保护垫、接触软垫、标准件防松和夹紧力仍需实测；
- 网顶承载条：连接左右立柱，首轮拆成 3 段约 `536 mm` 的搭接件，接缝下方用 2 片带 M3 孔的 `net_rail_splice` 拼接片锁紧（或替换为同接口铝型材），两端落在 `net_rail_saddle` 承托座上并由立柱侧端挡限位，支撑真实网布/白边；网布在装配时就属于本支架的一部分；
- PVDF 安装座：左右各一处，固定在网顶承载条附近；`pvdf_film` 由两侧可拆压片夹持，薄膜可替换，线束沿立柱走线；
- STG-120ML 光学安装：左右外侧使用 `stg120_outer_carrier`，中央使用 `stg120_center_bridge`，分别收纳外侧头和两只中央背靠背头；两段检测距离按约 `763 mm` 预留，光纤出口不急弯，商品头部孔位在实物量测前不写死；`stg120_preview` 只用于显示两段光路和 3.87 mm 光点参考，不作为打印件。

OpenSCAD 的 `assembly` 只用于整体关系预览；`left_stand`、`right_stand`、`post` 用于单侧结构装配检查，PVDF 座位于全宽网顶承载条中段，单独由 `sensor_mount` 或完整 `assembly` 检查；`lower_stand_segment`、上段 `post_segment`、`post_joint_sleeve`、`post_joint_key`、`table_clamp_body`、`clamp_top_pad`、`clamp_pressure_pad`、`clamp_knob`、`net_rail`、`net_rail_saddle`、`stg120_outer_carrier`、`stg120_center_bridge` 和 `calibration_gauge` 用于分件检查/导出，`stg120_preview` 仅为装配预览。球网、STG-120ML 光纤头、配套放大器、PVDF 薄膜、线束、M8 螺杆和软垫不被误认为打印件；`clamp_top_pad` 是接触保护界面，不承担 C 形夹结构力路。

### 3.2 STG-120ML 光纤头、安装与供电

- 当前商品 SKU 是 `对射 STG-120ML 金属线/精度 3.87 mm`；详情图可见约 `130×19×6 mm` 头部、有效检测面约 `120 mm`、`32×Ø0.25 mm` 纤芯和最大约 `1000 mm` 检测距离；
- 一对头不能直接跨过球台 `1525 mm` 全宽，当前机械采用“右外侧头—中央头”和“中央头—左外侧头”两段，每段先按约 `763 mm` 布置；
- 商品详情图明确提示光纤线需搭配放大器，并展示 `DC 12–24 V` 放大器输入范围；这不能证明光纤头本体需要 12–24 V，也没有证明放大器工作电流；
- 5 V 充电宝不能直接接已见的 12–24 V 放大器。移动供电只能在拿到放大器空载/工作/启动峰值电流后，再选 5 V→12 V 升压或 12 V 电源包，并给两套放大器、ESP32-S3、PVDF 前端和提示器留余量；
- 放大器输出可能是单一 NPN/PNP 开关量、模拟量或未确认的计数/位置量；没有引脚图和实测波形前，不把 `3.87 mm` 自动转换成 ESP32-S3 的 32/64 位 `beam_mask`；
- 放大器到 ESP32-S3 之间先使用光耦、开集电极电平接口或带输入保护的模拟量接口，禁止把 12–24 V 工业输出直接接进 GPIO/ADC；
- 机械标定规按 3.87 mm 光点间距记录高度基准；它验证的是头部机械位置，不等于放大器已经输出逐点高度。

机械首样首先确认：台面厚度是否适配、上下夹持面是否压稳、立柱是否倾斜或滑移、网布张力是否拉偏支架、左右光学模块是否平行。

## 4. 擦网检测

网顶白边左右各装一条可拆卸 PVDF 压电薄膜片。PVDF 用于动态应变、振动和冲击，不作为静态拉力传感器。

每路信号链为：

```text
PVDF → 输入保护/偏置 → 放大与带通滤波 ──→ 可调阈值比较器 → GPIO 低延迟触发
                                      └──→ ESP32-S3 ADC1 连续采样 → 短波形证据
```

首轮默认采样窗口：双通道、`16 kHz`、触发前 `20 ms`、触发后 `80 ms`。任一路达到有效阈值即可生成擦网候选，同时保留左右峰值、能量、持续时间、一致性质量和 `waveform_ref`。比较器只提供低延迟触发时间点，事件层等待 ADC1 波形完成后再计算特征。

若波形在等待窗口内没有完成，事件仍可超时输出，但必须带 `waveform_incomplete`；冷启动预触发历史不足时也不能把后窗口采满冒充完整帧。阈值、滤波和时间窗必须基于真实支架/真实网布记录收敛。

参考资料：[TE Connectivity 压电薄膜资料](https://www.te.com/en/product-CAT-PFS0004.html)。

## 5. 过网高度业务边界

当前硬件只能先冻结“检测窗口和机械安装边界”，不能提前冻结逐点高度算法：

- 若放大器能给出逐光点编号/位图，两段结果再映射成带段号的高度区间；
- 若放大器给出模拟位置量，经保护、分压和实测标定后换算高度；
- 若放大器只有单一 NPN/PNP 遮挡开关量，只能判断该分段有遮挡，不能独立证明过网高度；
- 事件层继续保留 `beam_mask`、最低/最高命中点、`beam_height_mm` 和 `quality_flags` 的兼容字段，但在放大器证据不足时必须为 `unknown` 或标记字段未验证；
- 外部设备、SmartPaddle/App 和 `NetEvent v0.1` 仍按时间戳传输，但不把某种传输协议当作传感器输出能力的证明。

启动自检或安装标定未通过时，事件保持 `unknown`（由校准健康门控制），并可附加 `beam_self_test_invalid`、`beam_channel_unhealthy` 或 `piezo_baseline_invalid`。当前仓库不虚构没有接入的发射器/接收器测量值。

## 6. 事件状态机

事件归并只面向单球、事件可分离场景：

1. 第一根光束被打断时开始光栅事件；
2. 所有光束恢复并保持短暂安静后结束光栅事件；
3. 在事件前后可配置窗口内关联 PVDF 擦网候选；
4. 关联成功为 `touch_over`，无擦网为 `clean_over`；
5. 擦网候选超时仍未形成光栅事件为 `touch_no_cross`；
6. 标定失效、波形不完整、传感器健康门失败、队列溢出或事件边界无法判断为 `unknown`。

事件契约独立于传输层，核心字段包括：

```json
{
  "type": "net_event",
  "schema_version": "0.1",
  "event_id": "uuid",
  "timestamp_us": 0,
  "calibration_id": "calibration-id",
  "beam_mask": 0,
  "beam_height_mm": [10, 40],
  "ball_bottom_gap_mm": [0, 10],
  "net_touch": {
    "triggered": true,
    "sensor_mask": 1,
    "peak": [0, 0],
    "energy": [0, 0],
    "duration_us": 0,
    "waveform_ref": "waveform-id"
  },
  "state": "touch_over",
  "quality_flags": []
}
```

RGB 灯和蜂鸣器区分正常过网、擦网过网、擦网未过网和无效状态。断链时事件进入设备 RAM 小环形缓存，恢复连接后按序补发；事件不绑定 BLE、WebSocket、MQTT 或 SSE 中的任何一种传输。

## 7. 阶段门

### 阶段 A：方案切换与边界固化

- 标记外挂 X 夹具为历史方案并保留旧几何回归；
- 以 `net_stand.scad` 建立当前参数源、打印清单、意图预览和验证脚本；
- 保持根目录 `README.md` 不改动；
- 不承诺最终精度或比赛级能力。

### 阶段 B：内置支架 CAD 与桌下夹持

- 编译左右完整支架、传统桌下夹持和光学/PVDF 安装位；
- 用同厚度样块检查上夹板、台底可动压块、M8 螺杆行程和软垫空间；
- 打印左右支架首样，确认安装/拆卸、倾斜、滑移和网布张力。

### 阶段 C：完整替换式球网样机

- 安装真实网布、网顶承载条、PVDF 夹片和线束；
- 安装两侧 STG-120ML 外侧托架、中央背靠背支撑桥、四根光纤头和配套线缆；
- 用 3.87 mm 标定规记录机械光点高度、两段跨度、左右平行度和线缆弯曲；放大器输出能力保持 `pending`。

### 阶段 D：传感器与业务固件

- 复用 SmartPaddle 的 ESP32-S3 基础设施模式；
- 保持两路 PVDF ADC1 短波形、STG 放大器输入适配、健康门、事件归并、提示和 RAM 缓存；在接口证据不足时输出 `unknown`，不伪造逐点高度；
- 优先接 SmartPaddle WebSocket，同时保留多传输适配边界。

### 阶段 E：完整样机验证

按 [`validation-matrix.zh-CN.md`](validation-matrix.zh-CN.md) 验证正常过网、擦网过网、擦网未过网、逐光束遮挡、启动自检、机械误报、断链补发、单球分离和外部时间戳回放。主机测试、CI 和 CAD 渲染不能替代真实球台、网布、PVDF、光电器件、ESP32-S3 接板或 SmartPaddle/App 联调记录。

## 8. 当前明确的待实测项

- 球台真实厚度、边缘形状、夹持空间、立柱材料和支架兼容范围；
- PETG 立柱/夹持件在目标夹紧力下的变形、倾斜和滑移；
- 网布张力、网顶白边刚度、PVDF 夹片压力、AFE 增益、带宽和阈值；
- STG-120ML 配套放大器具体型号、供电电流/启动峰值、输出语义、环境光抑制、两段同步方式和球体遮挡宽度；
- 事件归并窗口、安静时间、单球分离能力；
- 最终 PCB 引脚复用、启动自检测量和 SmartPaddle/App 真实传输联调。
