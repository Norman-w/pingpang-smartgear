# 乒乓智配：内置式球网支架、擦网与过网高度设备

## 1. 当前方案与边界

当前机械方向已经从“夹在原球网立柱两侧的外挂 X 夹具”切换为“直接替换传统球网的内置式球网支架” ：

- 左右立柱、桌下夹持、网布、网顶承载条和传感器安装位组成一套完整球网支架；
- 支架像传统网架一样从球台下方夹住台面，使用上下接触面和竖直螺杆夹紧；
- 网顶 PVDF 振动监测在装配时直接安装在支架网顶，不再依赖原球网立柱上的外挂夹片；
- 左右立柱承载全宽 10 路并行调制红外对射光栅，输出离散过网高度区间；
- ESP32-S3 继续生成独立的 `NetEvent v0.1`，与 BLE、WebSocket、MQTT、SSE 和 App 传输解耦；
- 首版不使用相机，不判断过网方向，不处理重叠多球，不宣称正式比赛裁判能力。

尺寸、阈值、时间窗和材料是首轮样机参数。真实球台厚度、网布张力、夹持力、PVDF 贴合方式、光学距离和环境光裕量必须通过实物记录后再收敛，当前不提交最终精度承诺。

旧的外挂方案保留在 `hardware/cad/net_post_x_clamp.scad`，只作为历史设计回溯和旧几何回归；当前机械参数源是 `hardware/cad/net_stand.scad`。

## 2. 系统分层

```text
替换式球网网顶 ── 左/右 PVDF 夹片 ── AFE ── 比较器 ──┐
                                                       ├─ ESP32-S3 业务事件层
全宽 10 路 IR 发射/接收 ── TIA/滤波/比较器 ────────────┘       │
                                                               ├─ RGB/蜂鸣器
                                                               ├─ SmartPaddle WebSocket 适配
                                                               └─ RAM 小环形缓存
```

BLE、Wi-Fi、WebSocket、MQTT、SSE、配网和 App 多设备基础设施不在本工程重新设计；本工程只提供传输无关的业务事件和首个适配接点。ESP32-S3 固件通过 `firmware/main/net_event_transport.h` 的连接 hook 接入 SmartPaddle 现有连接层；没有接入 hook 时保持 fail-closed，不假装已经联网。

## 3. 内置式球网支架与 OpenSCAD

### 3.1 支架主体

`hardware/cad/net_stand.scad` 是当前唯一参数源，坐标为 `x=球台宽度方向、y=球台长度方向、z=台面以上`。首轮参数：

| 项目 | 参数 |
| --- | ---: |
| 球台宽度 | `1525 mm` |
| 首轮台面厚度 | `25 mm` |
| 网顶高度 | `152.5 mm` |
| 立柱中心离台边 | `18 mm` |
| 光栅档位 | `+10…+100 mm`，10 mm 一档 |
| 网顶 PVDF 安装座 | 左右各 1 个 |
| 桌下夹紧螺杆 | M8 竖直螺杆/旋钮占位 |

每侧支架由以下部分组成：

- 立柱主体：从桌下夹持区域一直延伸到最高光栅模块上方，顶部承载网顶承载条和光学导轨；
- 传统桌下夹持：上、下接触面跨过台面边缘，外侧 C 形受力路径和竖直 M8 螺杆负责夹紧；螺杆与导向座位于台边外侧，整个支架免打孔安装，不允许螺杆穿过球台；接触软垫、螺纹件和夹紧力仍需实测；
- 网顶承载条：连接左右立柱，支撑真实网布/白边；网布在装配时就属于本支架的一部分；
- PVDF 安装座：左右各一处，固定在网顶承载条附近，薄膜可拆换，线束沿立柱走线；
- 光学导轨：左右立柱内侧安装发射/接收模块包络，装配时使用参考线和标定规校准。

OpenSCAD 的 `assembly` 只用于整体关系预览；`left_stand`、`right_stand`、`post`、`table_clamp`、`net_rail`、`optical_strip`、`sensor_mount` 和 `calibration_gauge` 用于分件检查/导出。球网、光学器件、PVDF 薄膜、线束、M8 标准件和软垫不被误认为打印件。

### 3.2 光栅与参考线

- 一侧为调制红外发射端，另一侧为光电二极管接收端；
- 10 路持续并行工作，不采用逐路低速轮询；
- 光束高度固定为网顶以上 `+10、+20、…、+100 mm`；
- 每个通道独立自检、记录对准质量和遮挡状态；
- 当前光学导轨提供每 `10 mm` 一个实际贯穿定位孔和刻度标记，参考线端座/标定规只允许停在这些档位，用于机械高度和光轴对准；
- 光栅输出高度区间，不输出连续毫米高度；完全高于 `+100 mm` 的球路不生成事件。

机械首样首先确认：台面厚度是否适配、上下夹持面是否压稳、立柱是否倾斜或滑移、网布张力是否拉偏支架、左右光学模块是否平行。

## 4. 擦网检测

网顶白边左右各装一条可拆卸 PVDF 压电薄膜片。PVDF 用于动态应变、振动和冲击，不作为静态拉力传感器。

每路信号链为：

```text
PVDF → 输入保护/偏置 → 放大与带通滤波 ──→ 可调阈值比较器 → GPIO 低延迟触发
                                      └──→ ESP32-S3 ADC1 连续采样 → 短波形证据
```

首轮默认采样窗口：双通道、`16 kHz`、触发前 `20 ms`、触发后 `80 ms`。任一路达到有效阈值即可生成擦网候选，同时保留左右峰值、能量、持续时间、一致性质量和 `waveform_ref`。比较器只提供低延迟触发时间点，事件层等待 ADC1 波形完成后再计算特征。

若波形在等待窗口内没有完成，事件仍可超时输出，但必须带 `waveform_incomplete`；冷启动预触发历史不足时也不能把后窗口采满冒充完整帧。阈值、滤波和时间窗必须基于真实支架/真实网布记录收敛。

参考资料：[TE Connectivity 压电薄膜资料](https://www.te.com/en/product-CAT-PFS0004.html)。

## 5. 过网高度检测

采用全宽、10 路并行持续检测的调制红外对射光栅：

- 左右内置立柱分别承载发射端和接收端；
- 每通道使用前置放大、滤波和比较器，独立输出到 ESP32-S3 GPIO/中断；
- 光学模块固定在当前支架的连续导轨上，通过机械参考线和标定规完成俯仰、偏航与零点确认；
- 光栅结果保存 `beam_mask`、最低/最高命中光束、`beam_height_mm`、`ball_bottom_gap_mm`、校准版本和质量标记。

调制红外 beam-break 是成熟的对射检测架构，但本工程不把低速遥控器接收头直接当作光栅接收器。参考资料：[Vishay 调制红外 beam-break 资料](https://www.vishay.com/docs/82729/tsspagcpsensor.pdf)。

启动自检或安装标定未通过时，事件保持 `unknown`（由校准健康门控制），并可附加 `beam_self_test_invalid`、`beam_channel_unhealthy` 或 `piezo_baseline_invalid`。当前仓库不虚构没有接入的发射器/接收器测量值。

## 6. 事件状态机

事件归并只面向单球、事件可分离场景：

1. 第一根光束被打断时开始光栅事件；
2. 所有光束恢复并保持短暂安静后结束光栅事件；
3. 在事件前后可配置窗口内关联 PVDF 擦网候选；
4. 关联成功为 `touch_over`，无擦网为 `clean_over`；
5. 擦网候选超时仍未形成光栅事件为 `touch_no_cross`；
6. 标定失效、波形不完整、传感器健康门失败、队列溢出或事件边界无法判断为 `unknown`。

事件契约独立于传输层，核心字段包括：

```json
{
  "type": "net_event",
  "schema_version": "0.1",
  "event_id": "uuid",
  "timestamp_us": 0,
  "calibration_id": "calibration-id",
  "beam_mask": 0,
  "beam_height_mm": [10, 40],
  "ball_bottom_gap_mm": [0, 10],
  "net_touch": {
    "triggered": true,
    "sensor_mask": 1,
    "peak": [0, 0],
    "energy": [0, 0],
    "waveform_ref": "waveform-id"
  },
  "state": "touch_over",
  "quality_flags": []
}
```

RGB 灯和蜂鸣器区分正常过网、擦网过网、擦网未过网和无效状态。断链时事件进入设备 RAM 小环形缓存，恢复连接后按序补发；事件不绑定 BLE、WebSocket、MQTT 或 SSE 中的任何一种传输。

## 7. 阶段门

### 阶段 A：方案切换与边界固化

- 标记外挂 X 夹具为历史方案并保留旧几何回归；
- 以 `net_stand.scad` 建立当前参数源、打印清单、意图预览和验证脚本；
- 保持根目录 `README.md` 不改动；
- 不承诺最终精度或比赛级能力。

### 阶段 B：内置支架 CAD 与桌下夹持

- 编译左右完整支架、传统桌下夹持和光学/PVDF 安装位；
- 用同厚度样块检查上下夹持面、M8 螺杆行程和软垫空间；
- 打印左右支架首样，确认安装/拆卸、倾斜、滑移和网布张力。

### 阶段 C：完整替换式球网样机

- 安装真实网布、网顶承载条、PVDF 夹片和线束；
- 安装 10 路光学模块和参考线/标定规；
- 记录网顶高度、左右立柱平行度、光学通道逐根对准和机械误报波形。

### 阶段 D：传感器与业务固件

- 复用 SmartPaddle 的 ESP32-S3 基础设施模式；
- 保持两路 PVDF ADC1 短波形、10 路光栅、健康门、事件归并、提示和 RAM 缓存；
- 优先接 SmartPaddle WebSocket，同时保留多传输适配边界。

### 阶段 E：完整样机验证

按 [`validation-matrix.zh-CN.md`](validation-matrix.zh-CN.md) 验证正常过网、擦网过网、擦网未过网、逐光束遮挡、启动自检、机械误报、断链补发、单球分离和外部时间戳回放。主机测试、CI 和 CAD 渲染不能替代真实球台、网布、PVDF、光电器件、ESP32-S3 接板或 SmartPaddle/App 联调记录。

## 8. 当前明确的待实测项

- 球台真实厚度、边缘形状、夹持空间、立柱材料和支架兼容范围；
- PETG 立柱/夹持件在目标夹紧力下的变形、倾斜和滑移；
- 网布张力、网顶白边刚度、PVDF 夹片压力、AFE 增益、带宽和阈值；
- 光电二极管距离、发射功率、环境光抑制、邻道串扰和球体遮挡宽度；
- 事件归并窗口、安静时间、单球分离能力；
- 最终 PCB 引脚复用、启动自检测量和 SmartPaddle/App 真实传输联调。
