# 乒乓智配：内置式球网支架、擦网与过网高度设备

> 当前机械主线改为用户选定 SKU `6122579349941` 的 M6 直角对射光电器件：左右各十路，装入 10×56×216 mm 可打印 PETG 长条主体和后盖 x 背面中央加厚 1/4-20 boss，再由竖直采购 13 mm 球头的上端 1/4-20 外牙沿 x 接入后盖隐藏螺母；球头下端默认 M8 外牙 z− 只保留为独立光学支撑接口，尚未与固定网柱连接。固定网柱从黄灰交界 z=16 mm 共面起一体实心延伸至 z=372.5 mm，不进入 C 形座；网布/卡夹功能区仍到 z=168.5 mm；检测器/球头总成沿 x 移到立柱中心只表示空间对准，取消旧版横向承托臂和旧版独立连接器。用户资料中“对射”条目标出 M6×0.75、20 m、NPN；同一张图的“反射”条目为 M6×0.5，不是当前器件。该 SKU 的最终型号后缀、有效螺纹长度、光学中心和独立输出数量仍待确认。STG-120ML 采购文档及旧版离散光栅/梳齿条只保留作历史回溯，不代表当前首样器件。

## 1. 当前方案与边界

当前机械方向已经从“夹在原球网立柱两侧的外挂 X 夹具”切换为“直接替换传统球网的内置式球网支架” ：

- 左右立柱、桌下夹持、真实网布和网端传感器安装位组成一套完整球网支架；网顶不设置轨道或承载条；
- 支架像传统网架一样从球台下方夹住台面，使用上下接触面和竖直螺杆夹紧；
- 网顶 PVDF 振动监测在装配时直接安装在支架网顶，不再依赖原球网立柱上的外挂夹片；
- 左右各有一套十路 M6 直角发射/接收器阵列，光学/M6 外丝轴沿 x，十个通道按 `20 mm` 节距单列装入宽体 PETG 主体；后盖 x 背面中央（y=0、z 中心）加厚 boss 开 x 向 Ø7.0 的 1/4-20 外牙通孔并隐藏标准螺母，采购球头保持竖直，上端 1/4-20 外牙沿 x 连接后盖，下端默认 M8 外牙 z− 接口仅保留独立光学支撑待定义，不进入 `z=16…168.5 mm` 固定网柱，也不在其顶面切孔；球头提供可锁紧的偏航/俯仰/滚转微调；旧版独立连接器不属于当前装配；
- M6 资料给出 20 m、10–30 V DC、NPN、约 8 mm 头部和约 14 mm 安装杆包络；最终后缀、有效螺纹长度、光学中心、输出数量和发射/接收对应关系仍待卖家/实物确认；
- ESP32-S3 继续生成独立的 `NetEvent v0.1`，与 BLE、WebSocket、MQTT、SSE 和 App 传输解耦；
- 首版不使用相机，不判断过网方向，不处理重叠多球，不宣称正式比赛裁判能力。

尺寸、阈值、时间窗和材料是首轮样机参数。真实球台厚度、网布张力、夹持力、PVDF 贴合方式、光学距离和环境光裕量必须通过实物记录后再收敛，当前不提交最终精度承诺。

旧的外挂方案保留在 `hardware/cad/net_post_x_clamp.scad`，只作为历史设计回溯和旧几何回归；当前机械参数源是 `hardware/cad/net_stand.scad`。

## 2. 系统分层

```text
替换式球网网顶 ── 左/右 PVDF 夹片 ── AFE ── 比较器 ──┐
                                                       ├─ ESP32-S3 业务事件层
M6 发射/接收器阵列 × 2 ── 接口/保护电路 ────────────────────┘       │
                                                               ├─ RGB/蜂鸣器
                                                               ├─ SmartPaddle WebSocket 适配
                                                               └─ RAM 小环形缓存
```

BLE、Wi-Fi、WebSocket、MQTT、SSE、配网和 App 多设备基础设施不在本工程重新设计；本工程只提供传输无关的业务事件和首个适配接点。ESP32-S3 固件通过 `firmware/main/net_event_transport.h` 的连接 hook 预留接入 SmartPaddle/目标连接层；当前工作树未包含该外部连接层，未接入 hook 时保持 fail-closed，不假装已经联网。

## 3. 内置式球网支架与 OpenSCAD

### 3.1 支架主体

`hardware/cad/net_stand.scad` 是当前唯一参数源，坐标为 `x=球台宽度方向、y=球台长度方向、z=台面以上`。首轮参数：

| 项目 | 参数 |
| --- | ---: |
| 球台宽度 | `1525 mm` |
| 首轮台面厚度 | `25 mm` |
| 网顶高度 | `152.5 mm` |
| 网柱外侧边界离台边 | `152.5 mm`（名义网架总宽 `1830 mm`） |
| 立柱中心离台边 | `138.5 mm`（28 mm 立柱宽度扣除半宽） |
| M6 光电阵列 | 左右各 10 路，原始基准 `+10…+190 mm`；总成上抬 `20 mm` 后安装高度 `+30…+210 mm`，中心距 `20 mm` |
| PETG 检测器主体 + 采购球头 | 每侧 1 套；主体为首样打印件，球头提供偏航/俯仰/滚转微调 |
| 网顶 PVDF 安装座 | 左右各 1 个 |
| 桌下夹紧螺杆 | M8×1.25 竖直圆头螺杆 + 双螺母捕获旋钮 |

尺寸依据：[ITTF Statutes 2026 官方文件](https://documents.ittf.sport/sites/default/files/public/2026-02/2026_Statutes_v1_consolidated_clean.pdf) 第 2.1.1、2.2.1–2.2.4 条：比赛面宽 `1525 mm`，网架包含网、悬挂、网柱和夹具，网柱外侧边界应在两侧边线外 `152.5 mm`。另外，[ITTF Technical Leaflet T2](https://documents.ittf.sport/sites/default/files/public/2020-11/2020_BoD_documents_FINAL.pdf) 对网柱水平部分给出不超过台边外 `160 mm` 的边界，并对可拆螺夹给出开口至少 `32 mm`、台下投影不超过 `100 mm`、台下宽度不超过 `60 mm` 的建议/限制。因而本方案把 `130 mm` 作为项目结构下限，把 `152.5 mm` 作为传统球网名义基准，把自定义夹体最外点控制为 `156 mm`；同时固定夹体外端与立柱下段宽端面齐平。它是训练/实验用传感器支架，不宣称 ITTF 认证。网布名义总宽为 `1830 mm`，实际商品网夹接口、台下净空和强度仍须首样量测。

每侧支架由以下部分组成：

- 立柱主体：`post_clamp_carrier` 是从黄灰交界 `z=16 mm` 共面起一体实心延伸至 `z=372.5 mm` 的整根立柱，保留连续网布过道；网布/卡夹功能区止于 `z=168.5 mm`；底面不向下插入 C 形座，顶端不切 M8 直连孔。固定灰色 `clamp_body_segment` 单独打印并提供最高水平承托面；草图中的鞋、裤裆和咯噔定位只作为历史沟通参考，不生成当前打印件。网布从球台中心侧穿入连续 y 向 `3 mm` 过道并止到连续立柱本体外表面，再由整高 U 形卡网夹从桌外侧沿 x 推入；卡夹两片 jaw 夹住网布，网布张力和绳的拉力负责压住卡夹，立柱内嵌单一被动止挡只防向外拔出，按开夹爪即可解锁，不使用穿钉；M6 球头下端的独立光学支撑尚待定义，不把兼容包络当作已完成承力件；
- 传统桌下夹持：固定 C 形夹体跨过台面边缘，上夹板下表面现场粘贴胶皮压住台面上表面；桌面夹持开口、台底可动圆盘压块和 M8 螺杆区域保留，桌边外侧非接触区改为沿 y 全深的实心桥体；上下两条结构夹持舌头同步向台内延长 `20 mm`，台下有效伸入由 `62 mm` 增至 `82 mm`，下舌头的 M8 压紧件位于该有效区段中点；台底可动圆盘压块放大为 `Ø50 mm`，由下方加长 M8 圆头螺杆顶起，圆头落入压块底面的浅收纳窝并夹紧；上下结构夹臂均加厚到 `14 mm`，固定 C 夹最高水平承托面位于 `z=16 mm`，整根网柱底面与其共面，不向下插入；开口之外的外侧下部为实心渐变支撑，靠球台侧厚 `40 mm`、外侧收口为 `14 mm` 并形成斜底；固定下臂捕获一枚 M8 螺母，螺杆下端再用两枚 M8 螺母预先对锁并装入外径 `36 mm`、18 齿圆角锯齿握持圈，使旋钮与螺杆刚性同步，避免依赖 PETG 内螺纹或形成未定义的双螺纹约束；螺杆圆头和压块始终位于台面下方，不穿过球台，整个支架免打孔安装；实心桥体/渐变支撑的层向、旋钮握持手感、上侧胶皮、圆盘压块顶面摩擦、标准件防松、加长丝杆长度和实际夹紧力仍需实测；
- 网布安装：按网柱外侧边界距台边 `152.5 mm` 的常规尺寸，网布名义总宽为 `1830 mm`；网顶不设置轨道、承载条、拼接片或承托座。网布先穿过立柱连续 `3 mm` 过道，端部止到连续立柱本体外表面，再把整高 U 形卡网夹从外侧开口沿 `x+ → x−` 滑入；外侧横梁负责止挡，夹爪夹住网布，网布/绳张力负责保持，立柱内嵌单一被动止挡只防向外拔出，无穿钉，不采用传统圆柱卡网件；
- PVDF 安装座：左右各一处，放在网端附近的网布白边/网架接口位置，与立柱保留 `18 mm` 横向净距；`pvdf_film` 由可拆压片夹持，薄膜可替换，线束沿立柱走线；
- M6 光学安装：左右各使用当前 `m6_detector_body`、`m6_detector_mount` 和 `m6_sensor_array`；直角器件的光学/M6 外丝轴沿 x 朝球台中心，尾线局部沿 z- 后绕 x 轴 -45°，十个通道按原始 `+10…+190 mm`、`20 mm` 节距单列布置，完整检测器/球头总成上抬 `20 mm` 后实际安装高度为 `+30…+210 mm`；M6 外丝从各自外侧穿过主体并由主体外表面一枚螺帽锁紧；x- 光学端为加大正球弧前盖，x+ 线缆端为接驳边直角且仅自身后端两角圆滑的后盖，底盖有约 Ø12 mm 统一套管孔。后盖 x 背面中央（y=0、z 中心）为加厚 boss，x 向 Ø7.0 通孔接采购球头上端的 1/4-20 外牙并由隐藏标准螺母锁紧；球头保持竖直，下端默认 M8 外牙 z− 接口仅保留独立光学支撑待定义的包络，不进入 `z=16…372.5 mm` 固定网柱，也不在其顶面切孔。固定网柱从黄灰交界 `z=16 mm` 共面起一体延伸至 `z=372.5 mm`，网布/卡夹功能区至 `z=168.5 mm`；M6 头部防转、线缆出口、boss 孔和最终网夹接口尺寸在实物量测前不冻结。

OpenSCAD 的 `assembly` 只用于整体关系预览；`left_stand`、`right_stand`、`post` 用于单侧结构装配检查；`post_clamp_carrier`、`clamp_body_segment`、`net_clamp_clip`、`table_clamp_body`、`clamp_pressure_pad`、`clamp_knob`、`m6_detector_body`、`m6_detector_shell_front`、`m6_detector_shell_rear`、`m6_detector_bottom_cover`、y+ UI 一体式填平固定板和 `calibration_gauge` 用于分件检查/导出，`post_clamp_slide_exploded`、`clamp_slide_fit_section` 与 `net_clamp_fit_section` 是真实装配截面/滑入证据；旧 `post_joint_*`、`net_rail*`、`m6_sensor_rail`、`m6_sensor_test_coupon`、`m6_gimbal` 和旧 `m6_machining_*` 仅保留作兼容/历史诊断。球网、M6 光电器件、采购球头、PVDF 薄膜、线束、M8 螺杆和软垫不被误认为 PETG 打印件；`clamp_top_pad` 是接触保护界面，不承担 C 形夹结构力路。

### 3.2 M6 直角对射、安装与微调

- 当前采购目标为 SKU `6122579349941`：M6 直角对射、NPN、0–20 m；图片中的 `VJTL06-20NZ/N3` 仅作型号映射候选，最终后缀必须让卖家回传确认；
- 图片的当前“对射”条目明确标注 M6×0.75，直角头部约 8 mm、安装杆包络约 14 mm、截面约 10 mm；上方“反射”条目的 M6×0.5 不适用于本项目。左右各 10 只，共 20 只形成 10 个对射高度通道；
- 当前是单列竖直安装，不采用旧版交错托舌；主体为 10×56×216 mm 长条，十个中心按 `20 mm` 节距布置，上下边框余量各 18 mm。每路使用 x 向光学过孔、浅 AF8 六角防转窝和外表面一枚原配螺帽，线缆不陷入铝材；
- 前后盖从 z+ 套入主体并共享 y± 连续边槽，前盖占 x− 半段、后盖占 x+ 半段；前盖只开十个光学孔，真实六角、蓝色护套、线缆和螺帽均收在外壳内，后盖 x 背面中央为加厚 1/4-20 boss，底盖提供开放线缆套管孔；
- 每侧基座采用竖直采购 13 mm 球头；商品上端固定螺纹为 1/4-20 外牙，沿 x 接入后盖隐藏螺母；下端默认选 `13mm球【M8外牙】`，M8 外牙 z− 接口仅作为独立光学支撑待定义，不进入 `z=16…372.5 mm` 固定网柱；固定网柱网布/卡夹功能区止于 `z=168.5 mm`，顶面无 M8 孔。球头锁紧后提供偏航、俯仰和绕光束 x 轴滚转微调，主体/boss 承担已冻结的上端接口载荷，PETG 外壳只负责保护/导向，必要时后续改 CNC 或加金属嵌件。其余 1/4 内牙、1/4 外牙、3/8 外牙、M6、M10 选项只有在实物螺纹确认并重新匹配接口后才替换；
- NPN 图示为棕线 +V、蓝线 0 V、黑线开集电极输出。传感器是 10–30 V 设备，必须经过光耦/晶体管电平转换再进入 ESP32-S3，不能直连 GPIO；
- 商家确认的 `5 ms` 是状态变化到输出完成变化的响应时间，不是必须连续遮挡 5 ms 的最小检测门槛；最小输入脉宽、输出脉宽和高速球体漏检率按 [`M6 5 ms 响应/最小遮挡实测方案`](m6-response-time-validation-v0.1.zh-CN.md) 验收；
- 没有卖家确认的独立接收输出数量、逐通道遮挡波形和发射/接收对应关系前，不把 10 个机械位置自动当成 10 个有效 `beam_mask` 位；
- 供电、线缆弯曲半径、环境光抑制和邻道串扰必须在接板前确认。

机械首样首先确认：台面厚度是否适配、上下夹持面是否压稳、立柱是否倾斜或滑移、网布张力是否拉偏支架、左右光学模块是否平行。

## 4. 擦网检测

网顶白边左右各装一条可拆卸 PVDF 压电薄膜片。PVDF 用于动态应变、振动和冲击，不作为静态拉力传感器。

每路信号链为：

```text
PVDF → 输入保护/偏置 → 放大与带通滤波 ──→ 可调阈值比较器 → GPIO 低延迟触发
                                      └──→ ESP32-S3 ADC1 连续采样 → 短波形证据
```

首轮默认采样窗口：双通道、`16 kHz`、触发前 `20 ms`、触发后 `80 ms`。任一路达到有效阈值即可生成擦网候选，同时保留左右峰值、能量、持续时间、一致性质量和 `waveform_ref`。比较器只提供低延迟触发时间点，事件层等待 ADC1 波形完成后再计算特征。

若波形在等待窗口内没有完成，事件仍可超时输出，但必须带 `waveform_incomplete`；冷启动预触发历史不足时也不能把后窗口采满冒充完整帧。阈值、滤波和时间窗必须基于真实支架/真实网布记录收敛。

参考资料：[TE Connectivity 压电薄膜资料](https://www.te.com/en/product-CAT-PFS0004.html)。

## 5. 过网高度业务边界

当前硬件只能先冻结“检测窗口和机械安装边界”，不能提前冻结逐点高度算法：

- 若放大器能给出逐光点编号/位图，两段结果再映射成带段号的高度区间；
- 若放大器给出模拟位置量，经保护、分压和实测标定后换算高度；
- 若放大器只有单一 NPN/PNP 遮挡开关量，只能判断该分段有遮挡，不能独立证明过网高度；
- 事件层继续保留 `beam_mask`、最低/最高命中点、`beam_height_mm` 和 `quality_flags` 的兼容字段，但在放大器证据不足时必须为 `unknown` 或标记字段未验证；
- 外部设备、SmartPaddle/App 和 `NetEvent v0.1` 仍按时间戳传输，但不把某种传输协议当作传感器输出能力的证明。

启动自检或安装标定未通过时，事件保持 `unknown`（由校准健康门控制），并可附加 `beam_self_test_invalid`、`beam_channel_unhealthy` 或 `piezo_baseline_invalid`。当前仓库不虚构没有接入的发射器/接收器测量值。

## 6. 事件状态机

事件归并只面向单球、事件可分离场景：

1. 第一根光束被打断时开始光栅事件；
2. 所有光束恢复并保持短暂安静后结束光栅事件；
3. 在事件前后可配置窗口内关联 PVDF 擦网候选；
4. 关联成功为 `touch_over`，无擦网为 `clean_over`；
5. 擦网候选超时仍未形成光栅事件为 `touch_no_cross`；
6. 标定失效、波形不完整、传感器健康门失败、队列溢出或事件边界无法判断为 `unknown`。

事件契约独立于传输层，核心字段包括：

## 7. 阶段门

### 阶段 A：方案切换与边界固化

- 标记外挂 X 夹具为历史方案并保留旧几何回归；
- 以 `net_stand.scad` 建立当前参数源、打印清单、意图预览和验证脚本；
- 同步根目录 `README.md` 的当前结构说明；
- 不承诺最终精度或比赛级能力。

### 阶段 B：内置支架 CAD 与桌下夹持

- 编译左右完整支架、传统桌下夹持和光学/PVDF 安装位；
- 用同厚度样块检查上夹板、台底可动压块、M8 螺杆行程和软垫空间；
- 打印左右支架首样，确认安装/拆卸、倾斜、滑移和网布张力。

### 阶段 C：完整替换式球网样机

- 安装真实网布、PVDF 夹片和线束；网布从球台中心侧穿过两侧立柱的 `3 mm` 过道，端部止到立柱外表面，再将两件整高 U 形卡网夹从桌外侧沿 x 推入，记录网布/绳张力、内嵌止挡防拔行程、实际夹持力和按开夹爪后的脱开力；不装穿钉；
- 先用一孔主体/fit coupon 验证 M6×0.75 直角器件、浅六角防转、单枚螺帽和 -45° 线缆让位，再安装左右两套 M6 PETG 长条主体、前后盖、底盖和采购球头，装入 20 个器件和线束；球头上端 1/4-20 外牙直接从各自 x 后端进入后盖背面中央加厚 boss，下端默认 M8 外牙 z− 接口只记录独立光学支撑需求，不进入固定网柱；同时复核立柱底面 `z=16 mm` 共面、实体连续到 `z=372.5 mm`、网布/卡夹功能区止于 `z=168.5 mm`，以及从 `z=16` 起 `30 mm` 连续实心渐变到 `z=46` 后恒定 `28×38 mm` 的一体立柱；
- 用最低/最高/中间通道调偏航、俯仰、滚转，再做通道级高度补偿并锁紧；器件输出能力保持 `pending`，直到卖家资料、接线保护和实测波形闭环。

### 阶段 D：传感器与业务固件

- 复用 SmartPaddle 的 ESP32-S3 基础设施模式；
- 按 [`hardware/electronics/m6-capture-carrier-stm32g031k8-pinmap-v0.1.zh-CN.md`](../hardware/electronics/m6-capture-carrier-stm32g031k8-pinmap-v0.1.zh-CN.md) 以 `STM32G031K8U6/UFQFPN32` 作为独立载板工程候选，再把 10 路隔离输入、双边沿时间戳、SPI 从机 TX 预装、IRQ/CS 事务和时钟同步接到 ESP32-S3；CMSIS 寄存器绑定已通过目标架构 compile-only，但没有 DMA/定时器实测原型、最终 PCB 和联合 target 证据前，载板选择与 `kUseM6Carrier` 继续保持关闭；
- 保持两路 PVDF ADC1 短波形、M6 器件接口适配、健康门、事件归并、提示和 RAM 缓存；在接口证据不足时输出 `unknown`，不伪造逐点高度；
- 优先接 SmartPaddle WebSocket，同时保留多传输适配边界。

### 阶段 E：完整样机验证

按 [`validation-matrix.zh-CN.md`](validation-matrix.zh-CN.md) 验证正常过网、擦网过网、擦网未过网、逐光束遮挡、启动自检、机械误报、断链补发、单球分离和外部时间戳回放；另外必须关闭载板 MCU/PCB、SPI/IRQ/时钟同步、SmartPaddle `/ws` 联合 target 和 1–10 ms M6 波形门。主机测试、CI 和 CAD 渲染不能替代真实球台、网布、PVDF、光电器件、ESP32-S3 接板或 SmartPaddle/App 联调记录。

## 8. 当前明确的待实测项

- 球台真实厚度、边缘形状、夹持空间、立柱材料和支架兼容范围；
- PETG 立柱/夹持件在目标夹紧力下的变形、倾斜和滑移；
- 网布张力、网顶白边刚度、PVDF 夹片压力、AFE 增益、带宽和阈值；
- M6 器件最终后缀、M6×0.75 有效长度、头部防转、光学中心、供电电流、NPN 输出语义/数量、环境光抑制、邻道串扰、5 ms 响应对应的最小输入脉宽/输出脉宽和球体遮挡宽度；
- 事件归并窗口、安静时间、单球分离能力；
- 载板 MCU/封装与 PCB 引脚复用、启动自检实测、SPI/IRQ/时钟同步、SmartPaddle 联合 target/真实传输联调。
