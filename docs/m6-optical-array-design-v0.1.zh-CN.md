# M6 直角对射十路 45° L 型检测器与球头微调结构 v0.6

状态：`当前 CAD 主线已冻结 PETG 长条主体、传感器姿态和采购球头接口；壳体已按 x 光学端/线缆端分段落地为装配候选，实物尺寸待首样放行`。

用户指定采购目标为 M6 激光 L 型对射、0–20 m、NPN 输出，链接 SKU 为 `6122579349941`。供应商图片资料、M4/M3 同系列尺寸和 NPN 接线图已归档；型号后缀、有效螺纹和实际包装仍需向卖家/实物确认。

## 1. 坐标和方向

- `x`：发射/接收光轴，也是主体的厚度/传感器插入轴；右侧接收器光学面朝 `x-`，左侧发射器镜像后光学面朝 `x+`；
- `z`：竖直向上，球台台面为 `z=0`，10 个通道是 `+10…+190 mm`，中心距 `20 mm`；
- `y`：主体的加宽方向/球台前后方向；M6 L 型器件的出光/受光面和 M6 外丝轴沿 `x` 水平朝球台中心，蓝色护套/尾线局部先朝 `z-`，再绕光束轴 `x` 旋转 `-45°`，因此从主体 `y-` 后方斜向让位；壳体沿 `x` 分成光学前盖和线缆后盖；
- 两侧主体用 `SIDE=1/-1` 做 x 镜像，保持光束方向相反、结构左右对称。

这套定义明确把两条轴分开：光学轴与 M6 外丝同轴、都沿左右方向；垂直于它的蓝色护套/尾线支路才是 L 型的另一条方向。供应商图纸给出总水平包络约 `20 mm`，其中水平 M6×0.75 外丝段约 `14 mm`。同一侧十个器件采用同一 `-45°` 滚转角，尾线沿 `y-/z-` 方向让开相邻通道。

## 2. 长条主体

主体当前是一根可打印 PETG 连续长条，不是旧版梳齿条；后续可按同一包络改做 CNC/金属件：

```text
局部尺寸：x=10 mm，y=56 mm，z=216 mm
通道中心：z=+10,+30,...,+190 mm（相对球台面）
上下边框：各 18 mm（按当前传感器外形和 20 mm 节距余量）
```

主体厚度由实物安装杆约束：

```text
14 mm 外丝段 + 2 mm 头部卡入 − 5 mm 一枚外螺帽 − 1 mm 端部余量 = 10 mm 最大主体厚度
当前 CAD 主体厚度 = 10 mm，名义余量 = 0 mm；首件需按实物螺帽/有效外丝复核
```

每个通道包含：沿 x 的 `Ø6.6` 水平 M6 外丝通孔、采购件六角头让位、以及随 `x=-45°` 滚转的蓝色护套/尾线让位和 x 向浅六角窝 AF8×2.1。孔组形成“外侧插入 + 斜向出线”的安装位：右侧器件从 `x+`、左侧器件从 `x-` 外侧进入，水平外丝穿过主体；六角窝只卡住真实金属六角，不能做成深腔而顶住六角/外丝接驳处的平面。每个通道只在主体外表面安装一枚原配螺帽，不能把固定螺丝嵌入主体。主体孔和六角窝是机械定位特征，不是用打印壳承力。

当前是单列竖直安装，光学中心和 PETG 主体都位于 `y=0`，主体包络为 `10×56×216 mm`；不采用左右交错。右侧接收器从外侧 `x+` 装入，左侧发射器从外侧 `x-` 镜像装入；加宽主体用光学过孔、头部让位和浅 x 向六角座承接器件，朝台内平滑面安装一枚原配螺帽，线缆不陷入主体。若实物头部宽度或线缆与当前 45° 让线仍有干涉，先以实测干涉位置调整滚转角/孔位，不恢复旧版梳齿条。

## 3. 前后壳和底盖（当前装配候选，待首样放行）

当前前后壳和底盖已经按总成重新建模，用于装配/方向检查；它们仍不是最终打印放行件，需在主体实物单孔试装、线缆走向和球头接口确认后冻结尺寸。当前结构为：

- 从 `z+` 俯视，前盖位于光学端 `x-`，外形为正圆弧；后盖位于线缆端 `x+`，外形为圆角矩形，并在 x+ 背面中央（y=0、z 中心）增加后盖加厚 M8 boss；中间只表示前后盖分型边界，不建连线；采购球头 M8 外牙沿 x 进入 boss 通孔；
- 壳体从主体上方 `z+` 套入，主体 `y±` 两侧各有一条连续竖槽，前盖和后盖分别占用同一条槽的 `x-` / `x+` 半段，舌片保留 `0.25 mm` 装配间隙；
- 前后盖使用沉头螺丝固定到 PETG/CNC 主体，槽/舌负责装配定位；
- 底盖按主体下方截面封住下口，用沉头螺丝固定；底盖中央开放 `Ø12 mm` 过孔，剥去各传感器外皮后用统一套管引出线缆；不做防水声明。

壳体只应保护和导向；当前包络、槽舌和底盖孔位都是首样候选尺寸，不作为最终加工尺寸。承力路径为：

```text
M6 头部六角/外螺帽 → PETG 长条主体（后续可 CNC/金属化）
→ 后盖 x 背面中央加厚 boss / 必要时金属嵌件 → 采购 13 mm 球头
→ 球头 z− 接口 → 采购金属 90°连接器 → 两枚 M6 贯穿螺栓 → 网架立柱（直连，无中间转接板）
```

## 4. 球头和网架连接

不直接打印云台。当前模型使用采购的 13 mm 球头并保持球头主体竖直：

```text
后盖背面中央加厚 boss 的 x 向 Ø8.6 M8 通孔
        ↓
采购球头侧向 M8 外牙 / 球头壳体
        ↓（竖直下方螺柱）
球头 z− 接口向下 → 金属 90°连接器（最低端起向上 49 mm）→ 网架立柱 M6 贯穿孔（直连）
```

允许采购选项为：`13mm球【1/4内牙】`、`13mm球【1/4外牙】`、`13mm球【3/8外牙】`、`13mm球【M6外牙】`、`13mm球【M8外牙】`、`13mm球【M10外牙】`。当前视觉/规格默认 M8 外牙，但未将其他选项伪装成已确定尺寸；到货后只改球头侧转接孔/紧固件。

网架立柱接口仍是“待实测接口”：当前 CAD 保留采购球头 z− 竖直接口和外购金属 90°连接器占位；连接器从接口最低端向上到网架立柱孔中心，当前基准高差为 `49 mm`，并以两枚 M6 贯穿螺栓直接连接网架立柱，不经过中间转接板。商品网夹的固定面、孔距、夹具外伸、垫片和通栓长度必须按实物重测。

## 5. 微调方式

球头提供粗调/锁紧，目标是匹配左右发射和接收阵列：

1. 先调球头整体偏航，使低、中、高通道的左右方向都落在接收面；
2. 调俯仰，使最低和最高通道同时通过；
3. 调滚转，使十路竖直间距和对侧十路对应；
4. 球头旋钮锁紧后，以最低/中间/最高三路复核并记录锁紧前后偏移。

球头本体应承担微调和锁紧，不让薄 PETG 壳或细牙顶丝成为唯一承力件。若首样载荷不足，优先在后盖 boss 内加入金属嵌件或将后盖改做 CNC；不再另造 90°支撑或适配板，也不把不可测的打印摩擦当作调节机构。
